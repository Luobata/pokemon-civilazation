# 宝可梦 × 文明 4X

一个本地运行的宝可梦主题 4X 策略游戏：在六角格大陆与海洋地图上探索、捕捉和进化宝可梦，建设城市与设施区、研究分支科技树、挑战道馆巡回与四天王、与其他文明外交或战争。默认包含 9 位领袖、115 种宝可梦（每局按种子抽取地区图鉴）、分支科技树、绘卷插画地图与自研 Web Audio 原创配乐。

## 启动

需要 Node.js 22+ 和 npm。

```bash
npm install
npm run dev
```

打开终端中 Vite 显示的本地地址（通常为 `http://127.0.0.1:5173/`）。请通过该地址访问，直接打开或预览源 HTML 文件无法执行游戏入口。生产构建使用 `npm run build`，产物同样需通过 HTTP 服务访问；基础设计见 [mvp-gdd.md](docs/design/mvp-gdd.md)。

本地联机需要另开终端运行 `npm run server`（默认 `http://127.0.0.1:8787`），然后在页面服务的 `/multiplayer.html` 创建房间、打开座位 1，并将其余座位链接交给同一台机器上的其他浏览器窗口。`8787` 是 API 服务端口，页面使用 Vite 地址。服务默认仅监听回环地址，跨设备联机需另行部署。[多人服务及内容编辑器说明](docs/tech/network-and-editor.md)。

其他入口：
- `/guide.html`：数据驱动的训练家手册与数值表
- `/audit.html`：系统说明与隔离沙盒审计台
- `/editor.html`：隔离内容编辑器

## 新局设置

可选择 9 位领袖（大木博士、渡、君莎小姐、乔伊小姐、小刚、小霞、大吾、阿蜜、坂木）、御三家、地图尺寸（小 24×16、标准 30×20、大 40×26、超大 56×36）、世代进程、轮上限（100/200/300 轮）、AI 数量和 AI 性格。点击“新游戏”后生效。

世代默认精简为**初代（红／绿／蓝／黄）→ 金银世代 → 宝石世代**；完整模式涵盖初代至朱紫九世代。研究采用 30 项前置依赖的分支科技树，含图鉴发现加速与时代献礼。联机建房同样支持世代进程与各座位领袖。[规则和征服对局诊断](docs/design/era-conquest-balance.md)。

## 画风与地图视角

支持在游戏菜单切换画风与地图视角：
- **绘卷（插画，默认）**：基于原创 CC0 SVG 地图素材组合渲染的绘卷插画地图与羊皮纸迷雾。
- **像素（2.5D 立体 / 平面）**：经典像素贴图风格，可选 2.5D 地形抬升视角与小地图，或传统平面视角。

## 基本操作

- **选择与地图**：点击己方城市或单位，操作面板会切换到对应对象；同格存在城市、战斗宝可梦与职能单位时，再次点击可切换。点击高亮空地可移动，右键远处格子可设置多回合前往路标。拖动地图平移，滚轮缩放；`F` 恢复全图视野。未探索区域全黑，已探索但当前不可见的区域保留记忆地形。
- **攻击**：选择宝可梦后点击“攻击”（`A`），选择红色虚线标记的敌方单位或城市，查看文明 6 式战斗力明细与伤害预览，再次点击目标或确认发起攻击。
- **捕捉**：研究「驯化」并在城市购买精灵球后，选择宝可梦，点击“捕捉”（`Q`），选择野生目标与球种并确认。只能捕捉野生宝可梦，不能捕捉其他文明、劲敌或团体战头目。
- **进化**：单位经验、金币、科技或进化石条件满足时，单位面板会提供进化按钮（阶段 1 单位在金银世代起可使用神奇糖果以额外金币提前进化）。
- **建城与改良**：开拓队在距其他城市至少 4 格的可通行陆地建立新城市；工匠负责建设/修复地块改良；商队开通国内商路；城市支持建筑、宝可梦、职能单位、设施区、传说奇观与可重复城市计划。
- **道馆、劲敌与联盟大会**：世界地图分布中立巡回道馆、自然地标、巢穴、霸主与极巨巢穴；支持单打接力形式的道馆战、四天王挑战、圣所守卫战、劲敌对决与定期联盟大会。
- **研究与规章**：通过 30 项分支科技树研究课题；通过联盟体制、规章与方针卡调整文明加成。
- **外交与回合**：外交面板支持宣战、停战、贸易与同盟。点击“下一回合”会先引导至待办事项，Shift+点击或 `Ctrl/⌘ + Enter` 直接结束回合。
- **存读档**：保存/读档使用当前浏览器的 `localStorage`；支持导出/导入存档 JSON；开发模式（`?dev=1`）支持导出命令日志、重放与上帝视角。

### 快捷键

- 方向键：移动地图光标；`Enter`：选择或确认移动；`Esc`：取消
- `+` / `-`：缩放；`F`：地图居中；`Y`：切换地块产出显示
- `C`：聚焦城市；`R` / `T`：打开研究；`,` / `.`：切换待命单位
- 单位行动：`M` 移动、`W` 前往、`A` 攻击、`Q` 捕捉、`E` 进化、`B` 建城、`I` 改良、`Space` 跳过
- `Ctrl/⌘ + Enter`：直接结束回合；`?`：打开键盘帮助

## 胜利条件

- **征服胜利**：攻下其他所有文明的联盟总部。自己的联盟总部失守即失败。
- **图鉴胜利**：按本局地区图鉴规模记录目标数量的物种（观察 + 对战或收服）。
- **起源胜利**：击败四座圣所守卫，集齐四块起源石板。
- **冠军胜利**：赢得两届联盟大会冠军（或通关四天王折算 1 冠）。
- **华丽大赛胜利**：建成大赛馆并累计达到目标人气值。
- **传说信仰胜利**：创立信仰并使目标比例的城市改宗。
- **轮上限计分**：完成最后一轮后，按城市、人口、历史登记物种、科技与击坠数计分。

## 测试与开发命令

- `npm run check:plan`：查看当前改动所需的分层检查计划
- `npm run check`：执行增量检查（含 QUICK smoke 抽样）
- `npm run check:merge`：合入前完整检查（含 48 局 smoke 逐字节验证）
- `npm run check:full`：全量门禁检查
- `npx vitest run`：运行规则、AI、网络、编辑器与工具单元测试
- `npx playwright test` / `npm run test:e2e:prod`：运行开发态与生产构建浏览器 E2E 测试
- `npm run sim:leaders`：运行领袖受控对局模拟

## 已知限制

- 已支持本地单机及本机权威多人；尚未提供公网部署与账号服务。
- 存档带有明确 schema、规则和内容版本校验，不兼容版本会拒绝加载，暂不提供跨版本存档迁移。
