# 宝可梦 × 文明 4X

一个本地运行的宝可梦主题 4X 策略游戏 MVP：在六角格地图上探索、捕捉和进化宝可梦，建设城市、研究科技、与其他文明外交或战争，最终通过征服或轮上限计分获胜。

## 启动

需要 Node.js 22 和 npm。

```bash
npm install
npm run dev
```

打开终端中 Vite 显示的本地地址。生产构建使用 `npm run build`；完整规则以 `docs/design/mvp-gdd.md` 为准。

## 新局设置

可选择御三家、地图尺寸（小 24×16、标准 30×20、大 40×26）、轮上限（100/200/300 轮）、AI 数量和 AI 性格。点击“新游戏”后生效。

## 基本操作

- **地图**：点击己方单位进行选择，再点击高亮格移动。拖动地图平移，滚轮缩放；“F 地图居中”恢复全图视野。未探索区域全黑，已探索但当前不可见的区域只保留记忆地形。
- **攻击**：选择宝可梦后点击“攻击”，选择红色虚线标记的敌方单位或城市，查看伤害、反击和击坠预览，再确认。攻击敌方文明需先处于战争状态。
- **捕捉**：研究「驯化」并在城市购买精灵球后，选择宝可梦，点击“捕捉”，选择野生目标、球种并确认。只能捕捉野生宝可梦，不能捕捉其他文明的单位。
- **进化**：单位经验、金币和科技条件满足时，单位面板会提供进化按钮。进化消耗该单位当回合行动。
- **城市**：选择开拓队后点击“开拓队建城”。城市面板可切换城市、分配/锁定工作地块、调整最多 5 项的生产队列、购买精灵球。未分配工作的人口成为观测者并提供科研。
- **研究**：在研究区域选择课题并点击“选择研究”。未选课题时科研进入储备；切换课题保留进度。
- **外交**：外交面板可宣战或提出停战。收到停战提议时必须接受或拒绝，回应前不能结束回合或切换对局。
- **回合**：点击“结束回合”完成当前文明的行动。AI 会自动行动；动画期间可跳过演出。
- **存读档**：保存/读档使用当前浏览器的 localStorage；“导出存档 JSON”和“导入存档”用于文件转移。开发抽屉还可导出命令日志并重放。

### 快捷键

- 方向键：移动地图光标；Enter：选择或确认移动；Esc：取消
- `+` / `-`：缩放；`F`：地图居中
- `C`：聚焦城市选择；`R` / `T`：聚焦研究选择
- `Ctrl + Enter`：结束回合
- `?`：打开界面内的键盘帮助

## 胜利条件

- **征服胜利**：攻下其他所有文明的大本营。自己的大本营失守即失败。
- **轮上限计分**：完整进行最后一轮后，按城市、总人口、历史登记物种、完成科技和击坠数计分；仍存活的文明中最高分获胜，平分按规则依次比较，可并列。

## AI 性格

- **扩张型**：优先建城和经济，不主动宣战；战争中军力明显占优且接壤时可以有条件攻城。
- **好战型**：优先军事，满足军力和接壤条件时主动宣战，并会探索未知区域寻找敌方大本营。
- **保守型**：优先科技、经济及防御；军力至少为对方两倍且接壤时可主动宣战。该性格有意保留较弱强度，其对扩张型胜率仅作观察指标。

## 已知限制

- 仅支持本地单机，没有联机、图鉴/起源/冠军等后续版本系统。
- 存档有明确 schema、规则和内容版本；不兼容的旧版本会拒绝加载，暂不提供迁移。
- Canvas 使用色块与文字符号表现单位，不包含完整宝可梦图像资源。
- 开发抽屉、上帝视角和帧耗时仅用于开发诊断；性能数字取决于设备、浏览器、DPR 和场景，不能视为所有设备的保证。
