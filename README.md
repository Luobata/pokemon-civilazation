# 宝可梦 × 文明 4X

一个本地运行的宝可梦主题 4X 策略游戏 MVP：在六角格地图上探索、捕捉和进化宝可梦，建设城市、研究科技、与其他文明外交或战争，新局默认启用扩展 v1，含四位领袖、47 个物种、世界探索及多种胜利条件。

## 启动

需要 Node.js 22 和 npm。

```bash
npm install
npm run dev
```

打开终端中 Vite 显示的本地地址（通常为 `http://127.0.0.1:5173/`）。请通过该地址访问，直接打开或预览源 HTML 文件无法执行游戏入口。生产构建使用 `npm run build`，产物同样需通过 HTTP 服务访问；基础规则见 `docs/design/mvp-gdd.md`，扩展规则见 [扩展交付说明](docs/tech/expansion-delivery.md)。

本地联机需要另开终端运行 `npm run server`（默认 `http://127.0.0.1:8787`），然后在页面服务的 `/multiplayer.html` 创建房间、打开座位 1，并将其余座位链接交给同一台机器上的其他浏览器窗口。`8787` 是 API 服务端口，页面使用 Vite 地址。服务默认仅监听回环地址，跨设备联机需另行部署。[多人服务及内容编辑器说明](docs/tech/network-and-editor.md)。

其他入口：`/audit.html` 为系统审计台，`/editor.html` 为隔离内容编辑器。

## 新局设置

可选择御三家、地图尺寸（小 24×16、标准 30×20、大 40×26）、轮上限（100/200/300 轮）、AI 数量和 AI 性格。点击“新游戏”后生效。

## 基本操作

- **选择与地图**：点击己方城市或单位，操作面板会切换到对应对象；也可以通过「行动对象」中的城市/单位列表选择并聚焦。城市与单位同格时，再次点击可切换。点击高亮空地可移动；进入己方城市时先点单位的「移动」，或右键目标格。拖动地图平移，滚轮缩放；“F 地图居中”恢复全图视野。未探索区域全黑，已探索但当前不可见的区域只保留记忆地形。
- **攻击**：选择宝可梦后点击“攻击”，选择红色虚线标记的敌方单位或城市，查看伤害、反击和击坠预览，再确认。攻击敌方文明需先处于战争状态。
- **捕捉**：研究「驯化」并在城市购买精灵球后，选择宝可梦，点击“捕捉”，选择野生目标、球种并确认。只能捕捉野生宝可梦，不能捕捉其他文明的单位。
- **进化**：单位经验、金币和科技条件满足时，单位面板会提供进化按钮。进化消耗该单位当回合行动。
- **建城**：开局自带一支开拓队；更多开拓队在「城市 → 生产 → 训练开拓队」中加入队列，花费 30 生产。选中开拓队，移至距其他城市至少 4 格的陆地，下一回合恢复行动点后点击「在此建立城市」。建城消耗该开拓队，并自动打开新城市。
- **城市与建筑**：城市面板分为生产、人口与地块、物资采购、研究。生产可建建筑、训练宝可梦或开拓队，共用最多 5 项的队列。点已建建筑进入相关操作：联盟总部训练开拓队，宝可梦中心训练宝可梦，精灵球工坊建造，树果园分配工作地块，友好商店采购，宝可梦研究所研究。建筑加成自动生效，原有生产与科技条件继续适用。未分配工作的人口成为观测者并提供科研。
- **领袖**：在页面底部的「下局领袖」人物卡中选择大木博士、渡、君莎小姐或乔伊小姐，默认大木博士；选择仅在点击「新游戏」后生效，御三家可独立选择。侧栏「当前领袖」显示本局实际身份、技能与御三家，可通过「选择下局领袖」快速定位配置区；旧存档仍显示氏族领袖并沿用原规则。对局结束后可修改领袖、地图与 AI 等配置再开始下一局。
- **研究**：在研究区域选择课题并点击“选择研究”。未选课题时科研进入储备；切换课题保留进度。
- **外交**：外交面板可宣战或提出停战。收到停战提议时必须接受或拒绝，回应前不能结束回合或切换对局。
- **回合**：点击“结束回合”完成当前文明的行动。AI 会自动行动；动画期间可跳过演出。
- **存读档**：保存/读档使用当前浏览器的 localStorage；“导出存档 JSON”和“导入存档”用于文件转移。开发抽屉还可导出命令日志并重放。

### 快捷键

- 方向键：移动地图光标；Enter：选择或确认移动；Esc：取消
- `+` / `-`：缩放；`F`：地图居中
- `C`：聚焦城市选择；`R` / `T`：聚焦研究选择
- `Ctrl + Enter`：结束回合
- `?`：打开界面内的键盘帮助

## 系统说明与调试后台

访问 `/audit.html`，或从游戏底部「开发、命令回放与调试 → 系统说明与审计后台」打开当前对局的副本。每个系统都有独立地址、规则说明、实现状态、当前数据和相关调试操作；后续系统明确标为待实现。

后台支持条件预检查、执行正式命令、AI 单步、撤销、重置和导出审计记录。操作在独立沙盒中执行，不自动写回原对局。[使用说明与推进顺序](docs/tech/system-audit.md)。

领袖受控对局模拟：`npm run sim:leaders -- --seeds 10 --round-limit 100 --out /tmp/pokemon-leaders.json`。[120 局实测报告与样本边界](docs/design/leader-balance-report.md)。

## 胜利条件

- **征服胜利**：攻下其他所有文明的联盟总部。自己的联盟总部失守即失败。
- **扩展胜利**：扩展 v1 还支持完整记录 18 属性图鉴、集齐四石板起源及两届大会冠军；具体条件见扩展系统面板与交付说明。
- **轮上限计分**：完整进行最后一轮后，按城市、总人口、历史登记物种、完成科技和击坠数计分；仍存活的文明中最高分获胜，平分按规则依次比较，可并列。

## AI 性格

- **扩张型**：优先建城和经济，不主动宣战；战争中军力明显占优且接壤时可以有条件攻城。
- **好战型**：优先军事，满足军力和接壤条件时主动宣战，并会探索未知区域寻找敌方联盟总部。
- **保守型**：优先科技、经济及防御；军力至少为对方两倍且接壤时可主动宣战。该性格有意保留较弱强度，其对扩张型胜率仅作观察指标。

## 已知限制

- 已支持本地单机及本机权威多人；尚未提供公网部署与账号服务。
- 存档有明确 schema、规则和内容版本；不兼容的旧版本会拒绝加载，暂不提供迁移。
- 扩展 v1 含 47 种宝可梦；经典存档沿用固定的 39 种定义。物种使用随项目保存的第三世代《绿宝石》贴图，城市与开拓队使用简化图标；地形仍是原型美术。[素材来源及版权说明](public/sprites/gen3/README.md)。
- 开发抽屉、上帝视角和帧耗时仅用于开发诊断；性能数字取决于设备、浏览器、DPR 和场景，不能视为所有设备的保证。
