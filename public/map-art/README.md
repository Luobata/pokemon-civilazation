# 绘卷地图素材（原创）

`painted/` 下的 SVG 是 绘卷（`?theme=painted`）地图的竖立物件、海岸边与城镇：树木（阔叶、椴树、冷杉、云杉、雪松、棕榈、枯树、焦木）、灌木与花丛、仙人掌、岩石、沙丘、雪堆、芦苇与睡莲、丘陵（草地 / 沙漠 / 雪原）、山（高峰、雪顶山、低山、远山）、火山、四种海岸边（沙滩、雪岸、岩岸、黑沙）、城镇建筑（三种民居、议事厅、首都城堡、城墙、奇观、集市）以及八处地形地标。

## 来源与许可

- **全部是本项目原创**：由本项目为这款游戏手绘（以代码生成路径的方式编写），不含、也不改编任何第三方图片、素材包或字体。`docs/design/map-art-options.md` 中对比过的第三方素材（Kenney、Battle for Wesnoth 等）只在本机临时目录里用于截图对比，从未进入仓库。
- **许可：本项目原创素材，许可待仓库所有者决定。** 仓库目前没有 LICENSE 文件，`docs/` 与提交历史中也没有为本项目原创素材声明过具体许可（`docs/design/roster-v14.md` 里的 “CC0” 指的是 PokeAPI/sprites 仓库本身，不是本项目）。在所有者确定之前，不要假定任何开放许可。
- 与 `public/buildings/` 的原创建筑图同等地位；宝可梦官方插画与像素图（`public/sprites/`）是另一回事，见各自的 `manifest.json`。

## 约定

- 每个文件的锚点 (0, 0) 是物件的着地点（树干根部、房屋正面中点、山体底边中点；地块大小的地标、城墙以地块中心为锚），100 单位 = 一个地块半径，西北受光，墨线色 `#2B1E10`。
- 城镇建筑通过根元素上的 CSS 变量取色：`--roof` / `--roof-edge`（屋顶）与 `--accent` / `--accent-light` / `--accent-dark`（阵营色）；窗户带 `data-win="x y"`，夜间窗灯据此点亮。
- 组合与变体在 `src/browser/render/painted/map-art-svg.ts`：按地块序号的稳定哈希选择变体，不在绘制时随机。
