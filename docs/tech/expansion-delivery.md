# 文明扩展交付与验收

本记录对应 2026-11-01 的扩展实现，更新现有 PR #1。`system-audit-validation.md` 与 `leader-balance-report.md` 保留上一批的历史证据，本轮证据以本文和新的扩展平衡报告为准。

## 规则与兼容性

新建浏览器游戏、多人房间、独立审计和编辑器默认开启 `expansionVersion: 1`，使用 `EXPANSION_CONTENT`（`expansion-v1`）。未带扩展版本的旧存档、命令回放和核心调用使用固定原始 39 种单属性定义的 `CONTENT`（`m3-v1`）；旧模式不初始化扩展实体或消耗扩展 RNG。不可变表的 canonical SHA-256 为 `51f734c6cdf29e822c2b958d6272d2bf4ea41a27569a11ce8ddbc1ce739bfee8`，扩展表为 `68224504087ac1c0e9d5214161754e6744374c367b547a17b3b7e796fad781b9`，均有固定哈希回归。

扩展状态有独立版本，所有行动仍通过共享 `step` 原子验证与提交。保存和读取保留 setup、内容版本及完整命令日志，并重新执行日志核对状态，拒绝篡改。多人命令由服务端从座位令牌确定行动者，玩家只收到各自迷雾视图。

47 个物种覆盖 18 属性，扩展伤害把主副防御属性倍率相乘，免疫保持为零；攻击使用主属性。研究后的单个弱点为 2.2 倍，因此双弱点为 4.84 倍。经典属性表保留。为满足同阶段 D15 单击不超过 HP 60% 的规则，扩展表在相同阶段预算内调整了小拳石、隆隆石、大岩蛇、喷火龙、暴鲤龙、妙蛙种子和鬼斯的 HP/攻防分配，训练成本没有增加。编辑器校验全表所有同阶段组合。

进化石路线必须走 `UseEvolutionStone`：普通 `Evolve` 在扩展中不能绕过石头消耗。旧模式保留原来的经验、金币和科技进化条件。

性能原始结果在 `data/expansion-performance.json`，记录了 Node、Chromium、CPU、DPR、场景种子、命令序号与内容版本。测量范围是本机 Canvas 绘制时间，不能推断其他设备的端到端帧率或网络延迟。

平衡报告为 `../design/leader-balance-expansion.md`，包含两份逐局 JSON、内容/工具/产物哈希和所有领袖的主动能力、专属招募与建筑活动计数。每批为 10 个地图种子 × 3 种 AI 性格 × 4 次座位轮换，两批合计 20 个地图种子、240 局。四领袖训练批胜利份额为 24.17% / 27.50% / 27.50% / 20.83%，留出批为 30.00% / 23.33% / 21.67% / 25.00%；最大差距分别为 6.67 和 8.33 个百分点，均达到 15%–35% 份额、差距 ≤15 个百分点的预设条件。多数结局为计分胜利，样本共享地形及随机流，报告不把这一小型确定性验证表述为长期平衡或统计显著性证明。

修复证据包括：普通进化不得绕过进化石；巢穴的活动单位列表不得带出迷雾内 ID；外交提案、拒绝与过期不得泄露给第三方；AI 的外交合法性、受控圣所献祭、首次专属招募与金币储备；真实 HTTP 入口的流式请求体上限。独立审查报告与最终平衡报告在本轮结束时一并归档。

## 独立复审与 QualityGate

核心独立复审见 `expansion-core-review.md`，网络/编辑器独立复审见 `expansion-network-review.md`，结论均为 `pass_with_risk`。工程师占领奖励、不可变旧内容、命令版本校验、读档竞态及扩展物种的默认寻路/AI/成本入口问题均已修复。核心最终源码指纹为 `3d883891203689f2952bf474c2181f38c769ae103d6f541654aa7f0991f4db8b`，网络/编辑器为 `e23939db83b3d5c1cd1e4d394ee0466372fc629e6bc756a61d1e9cf91dfa7baa`，两份报告记录范围、复现与验证。

QualityGate 本地最终门禁 `gate=pass`、`raw_gate=pass`、`block_merge=false`、`execution_complete=true`，0 条阻断/建议/影子/延期/豁免 finding，0 次修复轮次，未命中脚本规则。`quality_confidence=full` 只描述当前启用的检查；生产 TypeScript 编译、测试与 ESLint 由本项目命令独立执行。Mutation 默认暂停，本轮未执行；CLI 原始状态为 `not_applicable`，不能表述为 Mutation 通过。

中央语义评审已领取并消费完成结果：指纹 `qgcf_657e71aa088d34ead2d56c775056ac2a8e7c8643f83d4ef45f1cbb8786802cdd`，2 个模型分片、0 finding、0 拒绝裁决、0 `needs_contract`，未使用语义修复轮次。适用规则仅 `GEC-TYPED-CONFIGURATION-CONTRACT`，覆盖 `package.json`、贴图 manifest 与 `tsconfig.json`；它不覆盖 TypeScript 游戏逻辑。中央仓库接入仍返回 `unknown domain: microservice-backend`，但本次源码 bundle 提交与独立中央评审实际成功，两者状态分别记录。fast feedback 因无匹配脚本和超过 30 文件上限而跳过，没有启动引擎。可公开的结构化摘要见 `data/expansion-qualitygate.json`。

目录中的“已实现”是机制可用状态，不代表长期平衡、公开服务器运维或无限规模性能保证。联机交付的是可运行的本地/自托管服务器与浏览器客户端，没有执行公开部署。
