## 2. 问题一：哪些单位做成宝可梦

**方案 A · 保持人类开拓队**：最贴近原作，非战斗单位一眼可辨；缺点是和“宝可梦文明”的主题有点脱节。

**方案 B · 开拓队本身是宝可梦**（例如搬运型宝可梦）：主题一致；缺点是和战斗单位混在一起难分辨，还会引出“能不能捕捉/进化开拓宝可梦”之类的怪问题。

**方案 C（推荐）· 训练家开拓队 + 随行宝可梦**：开拓队仍是人类（非战斗、好辨认），训练时从已登记的物种里选一只随行宝可梦（不额外花钱，但该物种至少登记过）。建城时随行宝可梦的**属性决定新城市的开局特长**：

| 随行属性 | 新城开局 |
| --- | --- |
| 草 / 虫 | 首格耕作 +1 食物，送一块树果田进度 |
| 水 / 冰 | 沿海时直接送一座港口进度 50% |
| 岩石 / 地面 / 钢 | 城市 HP +10，首项建筑生产 +10 |
| 火 / 电 | 生产 +1（持续 10 轮） |
| 超能力 / 妖精 / 龙 | 科研 +1（持续 10 轮） |
| 其他 | 金币 +15 |

这让“建城前派谁去”成为一个选择，也让捕捉不同属性更有用。

**其他非战斗角色**（每项可单独决定）：
- **工人**：推荐保持“任何宝可梦都能施工”，但加一个原作式的“施工次数”上限更清楚；或者新增“工程宝可梦”定位（搬运小匠线等）。
- **商队**：推荐新增，配合问题二的国内商路，由“运输宝可梦”（例如飞行系、信使鸟）担任，被敌人攻击会被劫。
- **传教士**：推荐暂不做单位，保持城市动作。

## 3. 问题二：城市规划（我们自己的一套）

推荐分三层做，每层可单独决定：

**第 1 层 · 设施区互相加成**（改动小）：每个设施区与相邻设施区互相 +1 主产出（原作“区域相邻”）；另外设计几组“主题组合”，例如 研究所区 + 发电厂 相邻 → 研究 +1；道馆区 + 宝可梦中心城市 → 训练经验 +10；港口 + 花园 → 食物 +1。规划布局开始有讲究。

**第 2 层 · 建筑进入设施区**（改动中）：每个设施区有 2–3 座专属建筑（研究所区：宝可梦研究所 → 图鉴馆 → 博士实验室；道馆区：训练场 → 道馆 → 联盟训练营；港口：渡船码头 → 灯塔……），城市中心只保留少数通用建筑。没建对应设施区就不能造这类建筑，城市自然走向专业化。

**第 3 层 · 城市之间的加成（推荐做，这是“不同城市之间的属性加成”）**：
- **区域辐射**：部分高级建筑对 6 格内的所有己方城市生效，例如发电厂的“输电塔”给周围城市 生产 +2、宝可梦中心网络让周围城市里的单位多恢复 HP。城市间距因此有讲究（太近抢地块，太远吃不到辐射）。
- **属性城市**：城市建了某属性道馆后成为“X 系城市”，同属性城市之间每座 +1 对应产出（城市联盟）；不同属性城市相邻则互补（例如 草系城市 + 水系城市 → 两城各 食物 +1）。
- **国内商路**：商队宝可梦往返两座己方城市，给目的城市送食物/生产，给出发城市金币；路上可以被劫。
