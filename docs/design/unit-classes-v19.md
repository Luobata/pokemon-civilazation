# 兵种与属性契合 v19（实现规格）

- 依据：`docs/design/unit-classes-proposal.md` 与用户 2026-11-05 的答复——A/B/C/D 都做，但“宝可梦天然有很强的属性亲和，不一定完全照搬原作，要评估怎么结合得最好，不然就成了纯文明换皮”。
- 版本：`gameplayVersion: 19`（schema 14，`rulesVersion: 'classes-v19'`）。v≤18 的存档、命令日志和回放逐字节不变。数值在 `src/content/unit-classes.ts`。

## 设计原则：属性管“克谁”，兵种管“怎么打”

- **属性克制仍是主轴**（×2、×0.5、×0 的大幅波动），这是宝可梦的身份，不动。
- **兵种是战场打法**，只做小幅修正（×1.2），用来回答《文明》式的问题：谁冲锋、谁守线、谁防空。
- **把文明的骨架换成宝可梦自己的成长系统**，而不是照搬：
  - 《文明》的“科技解锁兵种” → 宝可梦的**秘传学习器**（冲浪、怪力、骑乘、飞翔）：学会了才能训练对应兵种。
  - 《文明》的“时代决定兵种等级” → 宝可梦的**道馆徽章与服从**：没有对应属性的徽章，最终形态不听指挥，不能训练。
  - 《文明》的“单位升级” → 宝可梦的**神奇糖果**：进入金银时代后，花金币让一阶宝可梦不靠经验直接进化。
  - 宝可梦独有的**属性契合**：兵种和属性对路（格斗系近战、岩石系攻城、飞行系空战）的宝可梦伤害 +15%。同一个定位里，属性对路的那只更强——这让 105 种宝可梦在同一兵种里也有取舍。

## 规则

### A. 兵种相克（宝可梦之间的每次攻击，含反击）

| 兵种 | 克制（伤害 ×1.2） | 被谁克制 |
| --- | --- | --- |
| 近战 | 快速（挡住冲锋） | 水面 |
| 快速 | 远程、攻城（近身冲击） | 近战 |
| 远程 | 飞行（对空）、水面（岸防） | 快速 |
| 飞行 | 攻城、水面（空袭） | 远程 |
| 水面 | 近战（陆军难以还手） | 远程、飞行 |
| 攻城 | — 攻击宝可梦 ×0.8（只擅长破城） | 快速、飞行 |
| 侦察 | — | — |

### 属性契合（+15% 伤害，攻击宝可梦和城市都算）

| 兵种 | 契合属性（主或副属性之一） |
| --- | --- |
| 近战 | 格斗、一般、恶 |
| 远程 | 火、电、超能力、冰 |
| 快速 | 电、恶、火 |
| 侦察 | 一般、飞行、虫 |
| 攻城 | 岩石、地面、钢 |
| 飞行 | 飞行、龙 |
| 水面 | 水、冰 |

### B. 秘传学习器解锁兵种（城市训练）

| 秘传 | 来自科技 | 解锁训练 |
| --- | --- | --- |
| 冲浪 | 驯化 | 水面 |
| 怪力 | 碎石工艺 | 攻城 |
| 骑乘 | 骑行驯服 | 快速（原有限制） |
| 飞翔 | 气象观测 | 飞行 |

近战、远程、侦察一开始就能训练。捕捉、进化得到的单位照常使用，只限制城市训练（包括科技和世代招募）。

### C. 徽章与神奇糖果

- **最终形态（三阶）的训练**需要：进入第 2 世代（金银），并且拥有该宝可梦主属性对应的**徽章**——己方任一城市建有该属性精华的属性道馆（例如喷火龙要“炎”道馆）。
- **神奇糖果**：进入第 2 世代后，一阶宝可梦可以不满足经验直接进化成二阶，花费 = 进化金币 ×3（通常 90 金），其余条件（世代、分支条件）不变。

### D. 界面与手册

- 城市“训练宝可梦”按兵种分组；已登记但不能训练的物种列在下面，写明缺什么（秘传 / 世代 / 徽章）。
- 单位面板写出兵种、克制关系和是否属性契合；攻击预览写出“兵种克制 ×1.2 / 属性契合 +15%”。
- 研究卡片写“学会秘传：飞翔（可训练飞行）”。
- 手册新章节「兵种与属性契合」：相克表、契合表、秘传表、徽章与糖果规则、每个兵种的代表宝可梦。

## AI

- 只训练当前能训练的物种（不会产生被拒命令）；训练评分加上兵种相克（对视野内交战对手，每只 ±4）与属性契合（+8）。
- 金币 ≥ 糖果花费 + 60 时，用神奇糖果进化一阶单位。

## 验收

v18 固定 48 局前后一致；v19 两次一致、全部正常结束、0 异常；结束方式变化 ≤ 20 个百分点；攻击预览与权威结算一致（单元测试）。另报告各兵种终局占比。

## 验收结果（2026-11-05）

- v18 固定 48 局改动前后 49/49 文件一致；v19 两次运行 49/49 一致；48 局全部正常结束，0 异常，拒绝 4 次（已有的迷雾选址）。
- 结束方式相对 v18：征服 12→9、图鉴 0→2、华丽大赛 9→10、积分与信仰不变，最大变化 6.3 个百分点；平均结束轮次 82.8 → 84.0。
- 终局兵种占比几乎没变（远程 33.9%、攻城 21.8%、近战 15.2%、飞行 11.6%、侦察 8.7%、快速 7.7%、水面 1.1%）；属性契合单位 65.9% → 68.3%。原因：AI 军队主要是御三家进化线（远程）和免费招募，兵种相克只是训练评分里的小加分。规则本身对玩家已经生效；要让 AI 阵容也随敌人变化，需要加大 AI 的兵种评分，作为下一步调参。
