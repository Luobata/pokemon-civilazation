# 兵种体系提案：让宝可梦的定位、科技和时代连起来（待评审）

- 状态：提案，等用户选择后实现。起因：用户 2026-11-05 指出“原作有近战、骑兵、建造单位，科技升级后能造飞机；我们宝可梦很多，但和玩法的结合有点浅”。
- 数据来自当前 `roster-v14` 内容（105 种）与 v18 规则。

## 1. 现状：定位只是一个标签

| 定位 | 物种数 | 现在影响什么 |
| --- | --- | --- |
| 近战 35 · 远程 22 · 飞行 11 · 侦察 10 · 攻城 10 · 快速 9 · 水面 8 | 105 | 只影响 3 件事：攻城倍率（攻城 ×1.3，侦察 ×0.6…）、控制区（近战/快速施加，侦察/飞行无视）、能走的地形 |

和《文明》比，缺了四样东西：

1. **兵种之间没有克制**。胜负只看属性克制（火克草）和数值。《文明》里长枪克骑兵、骑兵冲远程、远程打不还手，这层“兵种相克”完全没有。
2. **科技几乎不决定能造什么**。12 项科技里只有「骑行驯服」限制快速型训练；其余只是“各城可直接招募某一只”。只要抓到或进化出，**第一时代就能训练飞行、三阶最终形态**（比如巢穴抓到的月亮伊布，这也是它成为 AI 第三主力的原因）。
3. **时代不带来兵种换代**。《文明》每个时代把旧兵种升级成新兵种（剑士→火枪手）。我们的时代只解锁时代能力、领袖方针和世代招募，旧单位不会“过时”，新单位也不是“下一代兵种”。
4. **获取途径分散**：登记物种（捕捉/进化）、7 项科技各给一只、8 个世代各给一只，玩家看不出“现在我能造什么兵、下一个科技会给我什么兵”。

## 2. 提案（四块，可以分别选）

### A. 兵种相克（核心）

在属性倍率之外，再乘一个**兵种倍率**，预览与结算共用：

| 攻击方 → 克制 | 效果 | 对应《文明》 |
| --- | --- | --- |
| 近战 → 快速 | ×1.25（挡住冲锋） | 长枪兵克骑兵 |
| 快速 → 远程、攻城 | ×1.25（绕后冲击） | 骑兵冲远程/攻城 |
| 远程 → 飞行 | ×1.25（防空） | 防空单位 |
| 飞行 → 攻城、水面 | ×1.25（空袭） | 轰炸机 |
| 水面 → 站在海边的单位 | ×1.15（舰炮） | 海军压制 |
| 攻城 → 任何宝可梦 | ×0.8（不擅野战，只擅打城） | 攻城器械 |
| 侦察 | 无加成，视野 +1 | 侦察兵 |

已有的“远程打近战不吃反击”（射程差）保留。手册加一张兵种相克表，攻击预览里写“兵种克制 +25%”。

### B. 科技解锁兵种（像《文明》的科技树造兵）

**登记的物种还要有对应科技才能训练**（抓到的单位照常使用，只限制城市训练）：

| 定位 | 需要的科技 | 理由 |
| --- | --- | --- |
| 近战、侦察 | 无 | 开局兵种 |
| 远程 | 精灵球工艺 | 远程战术 |
| 快速 | 骑行驯服（已有） | 骑乘 |
| 攻城 | 碎石工艺 | 破城 |
| 水面 | 驯化（港口） | 下水 |
| 飞行 | 气象观测 | 掌握气流才能空战（≈《文明》的“飞行”科技） |

### C. 时代决定能训练几阶（兵种换代）

- 初代：可训练一、二阶；**金银起才能训练三阶**（完整进程是第 3 世代起）。野外抓到、进化得到的三阶照常使用。
- 进入新时代时，城市可以花金币把**上一时代的一阶单位直接升成二阶**（《文明》的单位升级），不需要经验，花费 = 进化金币 ×2。旧兵种因此有“过时、该升级”的感觉。

### D. 兵种档案与界面

- 图鉴（手册与游戏内）按定位分组：每个定位一页，列出“需要的科技、克制谁、被谁克制、代表宝可梦（按世代）”。
- 城市生产的“训练宝可梦”按定位分栏，未解锁的定位显示所需科技（灰色）。
- 研究页面每项科技写明“解锁兵种：飞行”等。

## 3. 风险与验证

- A 会改变所有战斗结果，AI 训练评分要加兵种相克（现在已有属性克制评分，同样只看视野内的敌人）。
- B、C 会推迟飞行和三阶单位，前期节奏变慢；需要看结束方式和平均轮次。
- 全部放进新的玩法版本（v19），旧存档不变；验收沿用固定 48 局（前后一致、两次一致、结束方式变化 ≤ 20 个百分点），加一项：各定位终局占比都 ≥ 3%、单一定位 ≤ 40%（现在远程 33%、水面 1%）。
