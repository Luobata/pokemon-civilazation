# 宝可梦 × 文明：UI / 视觉规范（UI-1）

- 版本：v0.1（2026-10-28）
- 适用范围：MVP 浏览器界面；地图 Canvas2D，文字与操作原生 DOM/CSS，不使用 UI 框架。
- 信息依据：GDD v0.5 §7；技术文档 v0.5 §4；M1 截图 `reports/m1-play.png`、`reports/m1-fog.png`。
- 样稿：`docs/design/mockups/ui-mockup.html`，单文件、无外部资源，可离线打开。

## 1. 视觉方向

**设计概念：一本铺在深色作战桌上的“原野图鉴”——用纸张般清晰的面板承载文明决策，用简洁地形符号保留宝可梦世界的探索感。**

理由：这是个人学习项目，首要目标是规则可读、状态可核对、资源可离线替换，而不是模拟大型商业游戏的厚重 UI。当前 M1 已具备浅色底色和墨绿文字，应延续这一识别；需要改善的是控制项平铺、地图与面板层级不足、阵营与迷雾过度依赖颜色。

原则：

1. **地图优先**：主操作区至少占可用面积的 60%，面板不永久遮挡选合格。
2. **信息按决策排序**：先“现在能做什么”，再“为什么”，最后才是调试字段。
3. **颜色不是唯一通道**：群系带纹理，阵营带编号与纹样，状态带图标和文字。
4. **少而一致的演出**：动画解释状态变化，不延迟命令、不制造随机结果。
5. **离线可完成**：系统字体、色块简称、CSS/SVG 符号均有完整外观，缺精灵图不影响操作。

## 3. 地图规范

### 3.1 群系与六角格

默认 `HEX_RADIUS=22`，缩放范围沿用相机；1px 缝隙由浅色网格线形成，不以纯黑粗线分割。纹理在 100% 缩放下可辨，缩小后可省略细节但保留底色。

| 群系 | 底色 | 固定符号 / 纹理 | 禁止 |
|---|---|---|---|
| 草原 | `--biome-grassland` | 两簇短草线，位置由格子索引确定 | 每帧随机闪动草点 |
| 森林 | `--biome-forest` | 三个三角形树冠，底部短树干 | 用真实树木图片遮满格子 |
| 山地 | `--biome-mountain` | 双层折线山脊，高处朝格子上缘 | 仅凭灰色表达高地 |
| 海洋 | `--biome-ocean` | 两条水平波线，错开半格 | 动画水波干扰命中 |
| 荒漠 | `--biome-desert` | 两条缓弧沙丘与一个小圆点 | 高饱和黄色导致文字刺眼 |
| 雪原 | `--biome-snow` | 六向细雪晶或四点冰晶 | 未探索区也显示雪晶 |
| 火山 | `--biome-volcano` | 三角火山口与短熔岩折线 | 循环闪烁红光 |

纹理透明度约 12–22%，仅为辨识辅助。格子产出、坐标等调试信息不进入普通地形绘制。

### 3.2 迷雾三态与绘制顺序

| 状态 | 地形 | 实体 | 表现 |
|---|---|---|---|
| 未探索 | 不读取可见群系细节 | 不绘制 | 实心 `--fog-unexplored`，可有统一小点阵，但无任何地形纹理 |
| 已探索但不可见 | 只画最后已知地形，降饱和并叠 `--fog-remembered-tint` | 不画实时单位；历史标记仅按观察规则单独显示 | 加 45° 稀疏斜线 `--fog-remembered-hatch`，图例写“记忆” |
| 可见 | 当前地形 | 画观察投影允许的当前实体 | 不叠雾，纹理与提示完整 |

绘制顺序固定：地形 → 领地 → 城市/设施 → 单位 → 合法提示 → 迷雾 → 选择圈/允许显示的特效。**隐藏实体不得先画再用半透明雾遮住**；提示、伤害数字和捕捉演出也先按观察过滤。选择圈不能暴露不可见格中的单位。

### 3.3 领地、城市与阵营

- 领地只画外边缘，2px 阵营色 + 外侧 1px 深色衬线；相邻己方格之间不画内边。共享边界按实体 ID 只画一次。
- 城市为 26×26px 方框营地图标，顶部小旗含文明编号 1–4；下方 HP 条宽 32px、高 4px，仅受伤时出现。
- 大本营在城市图标中心加实心五角星，普通城市为空心方框，占领当轮加时钟标记和“暂停结算”提示。
- 阵营采用**颜色 + 数字 + 纹样**三重编码：1 墨青/实心、2 砖红/斜线、3 紫灰/圆点、4 赭金/交叉线。色弱模式下提高纹样密度，不要求用户辨色。
- 城市方框表示实体类型，不用城市外形区分阵营；阵营信息放在旗帜、编号和纹样中。

### 3.4 单位与精灵图替换规格

缺图时使用 **32×32px 圆角色块**：中央 1 个物种简称汉字，底部 4px 阵营纹样条与文明编号；已行动单位降低饱和度并显示小勾，不只降低透明度。野生单位去掉文明编号，改黄色小爪印；开拓队用“拓”和方角轮廓。

未来精灵图：

- 逻辑框 **48×48px**，资源建议 96×96px，透明 PNG/WebP，本地打包，无 CDN。
- 统一脚底锚点 `(24,40)`，对齐格子中心向下 6px；图形不得越出 48×48 资源框。
- 占位色块和精灵图共用 44×44px 最小命中区；选择圈、血条和阵营徽记仍由 Canvas 单独画，不烘进图片。
- 缩放到小于 75% 时切回简称色块，防止精灵细节和文字变成噪声。

### 3.5 选择、可达与攻击提示

- 悬停：2px `--map-hover` 内描边，格心显示小圆点；键盘焦点额外使用 `--color-focus`。
- 选中：半径 `0.72×HEX_RADIUS` 的 `--color-selection` 2.5px 选择圈，外加深色 1px 衬线；持续显示，不用呼吸闪烁。
- 可达：22% 青色填充 + 2px 实线，格心一个实心点；不可达不给同样边框。
- 攻击：20% 红色填充 + 2px 虚线，格心小交叉剑图标； hover 目标时再打开 DOM 战斗预览。
- 同时可达与可攻击：攻击样式优先，保留实心点表示也可移动；图例必须解释组合。
- 提示只来自合法命令查询，不在渲染层另算一套移动或攻击规则。

## 4. 面板与交互规范

### 4.1 通用状态

| 状态 | 视觉 | 行为 |
|---|---|---|
| 默认 | 表面底色、1px 边框、明确标签 | 可 Tab 到达 |
| 悬停 | 背景变为 `--color-accent-soft` 或边框加深 | 只预览，不提交命令 |
| 按下 | `translateY(1px)`，使用 active 深色，阴影收紧 | 松开才触发，移出取消 |
| 选中 | 2px 主色边框 + 左侧勾选/实心条 | `aria-selected` 或 `aria-pressed` |
| 键盘焦点 | 2px `--color-focus`，外偏移 2px | 不被选中框覆盖 |
| 禁用 | 灰底、禁用图标、原因文本或 tooltip | 原生 `disabled`，不响应快捷键 |
| 忙碌 | 保留原宽度， spinner + “结算中” | 禁止重复提交，相机仍可用 |
| 错误 | 危险色左边条 + 文字原因 | `role=alert`，焦点不强制跳走 |

### 4.2 主地图 HUD

L1 顶栏：轮次 `12/100`、金币 `50 (+4)`、科研 `2/轮`、维护 `-3`；当前文明编号与菜单居右。L2 地图占主视区。L3 选中对象卡。L4 小地图和主按钮“结束回合”。

- 资源变化用 `+4/-3` 和文字，不只用绿红；点击资源打开对应城市/研究说明。
- “结束回合”是唯一主色大按钮，至少 112×44px；有待行动单位时点击先显示确认，不直接跳过。
- 动画播放时禁用命令按钮并保留“跳过动画”；相机、缩放和帮助仍可用。
- 种子、命令序号、拒绝 JSON 等调试信息移到开发抽屉，普通模式不占首屏。

### 4.3 城市面板与建造队列

右侧 360px 抽屉，不随 Canvas 帧重建。层级：

1. L1 城名、人口、HP、四项产出与食物增长预测；样稿使用“青绿营地 · 人口2 · HP120/120”。
2. L2 “工作地块 / 建造队列”双标签；默认展示当前需要处理的一项。
3. L3 建筑槽与维护说明。
4. L4 添加订单、锁定地块、关闭面板。

建造队列最多 5 项，显示序号、名称、进度和待出场状态。拖动排序之外必须有“上移/下移”键盘按钮；首项取消需确认“已投入进度不退”。完成但无空格时显示独立“待出场”徽标，不占 5 项视觉配额。禁用订单在按钮下写资源或科技原因。

### 4.4 研究选择与科技树

研究选择先列出当前课题、进度和每轮科研，再列可研究项；切换不丢进度，但需明确“保留原进度”。

科技树沿用 GDD 三层，不用虚假前置连线：

- T1 三节点开局可选；完成任意 T1 后以虚线层级提示解锁 T2，T2 同理到 T3。
- 节点状态：已完成 ✓、研究中 ◐ + 数值、可研究空心、锁定锁图标。
- 样稿值使用“属性研究 ◐ 34/40”，T3 未解锁项不显示可点击样式。
- 节点点击在侧栏显示成本、效果和前置；确认后才提交研究命令。

### 4.5 单位面板

左下紧凑卡片：L1 名称、阶段、HP/EXP；L2 攻/防/移/程/P 与属性定位；L3 克制提示；L4 行动按钮。

样稿固定为“火恐龙 · 一阶，HP51/72，EXP238/250，攻76 防64 移3 程2 P10”。行动点耗尽时按钮禁用并写“本回合已行动”；进化按钮展示成本与科技原因，如“进化→喷火龙 80金 / 需要特训法”。休养、待出场和激怒用独立状态行，不压缩进 HP 数字。

### 4.6 战斗预览

居中但不遮攻击者与目标的预览卡，必须展示：双方 HP、预计伤害区间、克制和地形原因、固定反击、确认/取消。

样稿使用“火恐龙 → 妙蛙草，预计伤害17–21（拔群×2），预计反击2（草→火甚微，固定）”。区间来自 R85–100，不显示虚假单值；免疫写“无效”而不是 0 伤害。确认按钮使用危险色，仅预览悬浮不扣行动；Esc/取消返回地图。

### 4.7 响应式布局

- ≥1100px：顶部 HUD + 地图 + 右侧抽屉，单位卡浮于左下。
- 700–1099px：城市面板宽度 320px，资源条允许两行，科技树横向滚动。
- <700px：面板改全宽底部抽屉，主按钮固定底部安全区；地图保持至少 45vh，不强行压缩全部信息。
- 小屏不隐藏关键状态，改为分层标签；开发抽屉默认关闭。

## 5. 动效规范

| 场景 | 时长 | 缓动 | 表现 |
|---|---:|---|---|
| 移动 | 每格 180ms | `cubic-bezier(.2,.8,.2,1)` | 仅表现位置沿可见路径插值；隐藏段不显示 |
| 受击 | 260ms | `ease-out` | 目标偏移 3px 后归位，1 次明暗交替；HP 变化在终点核对 |
| 伤害数字 | 450ms | `cubic-bezier(.2,.8,.2,1)` | 上浮 12px 并淡出，只显示观察允许的值 |
| 捕捉 | 总计 600ms | 120ms `ease-in` + 180ms `ease-out` + 300ms `ease-in-out` | 球图标落入、一次轻摇、成功/失败标记；不额外抽 RNG |
| 面板 | 160ms | `ease-out` | 8px 位移 + 透明度，不阻挡已可用控件 |
| 悬停/选中 | 100ms | `ease-out` | 只过渡颜色、边框、阴影 |

“跳过动画”立即清空表现队列的临时位置、血量和图标，直接渲染权威最终状态，并保留一条文本事件摘要；不得重新结算、消耗 RNG 或改变命令顺序。读档、重开、切换观察者同样清队列。`prefers-reduced-motion: reduce` 下取消位移、摇晃和闪烁，只保留不超过 80ms 的透明度变化或直接终态。任何闪烁每秒不超过 3 次。

## 6. 可访问性

### 6.1 对比度

计算采用 WCAG 相对亮度；普通文字目标 ≥4.5:1，焦点等非文本目标 ≥3:1。脚本 `/tmp/ui_contrast.py` 的实测值：

| 前景 / 背景 | 对比度 | 结论 |
|---|---:|---|
| 主文字 `#1D2B26` / 应用底 `#F3F0E7` | 12.93:1 | 通过 |
| 主文字 / 面板 `#FFFDF7` | 14.48:1 | 通过 |
| 次级文字 `#52635B` / 面板 | 6.27:1 | 通过 |
| 弱化文字 `#5F6E66` / 面板 | 5.28:1 | 通过 |
| 按钮文字 `#FFFDF7` / 主色 `#2E6B55` | 6.16:1 | 通过 |

### 6.2 键盘与读屏

- `Tab/Shift+Tab` 按 HUD → 当前面板 → 地图 → 主按钮顺序移动；所有功能不依赖 hover。
- 地图获得焦点后，方向键移动格子光标，Enter 选择/确认，Esc 取消；`+/-` 缩放，`F` 居中。
- `C` 城市、`R` 研究、`T` 科技、`?` 快捷键帮助；输入框内不拦截字符快捷键。
- `Ctrl+Enter` 请求结束回合；有待行动单位时仍进入确认，不与浏览器/系统保留键冲突。
- Canvas 提供可读名称和当前格摘要；旁边 DOM 状态区以 `aria-live=polite` 宣读选择、移动结果和错误。隐藏格不进入可访问文本。
- 模态框使用原生 `<dialog>` 或等价焦点圈定，关闭后焦点回到触发按钮；抽屉不随意抢焦点。

### 6.3 色弱、缩放与减少动态

- 群系：颜色 + 固定纹理 + 图例文字；阵营：颜色 + 编号 + 纹样；范围：颜色 + 实虚线 + 图标。
- 200% 页面缩放仍允许面板滚动和按钮换行，不截断 HP、资源与结束回合按钮。
- 支持 `prefers-reduced-motion`，设置内另有“动画：完整/减少/跳过”；跳过状态不改变规则。
- 色弱模式增加纹样密度、实虚线差异和文字标签，不仅换另一套色板。

## 7. 实现建议与文件清单

### 7.1 Canvas 与 DOM 分工

**Canvas2D**：六角格底色与纹理、领地边缘、城市/单位标记、合法范围、迷雾、选择圈、位置/受击/捕捉临时表现。继续单 Canvas、视口内绘制、DPR≤2、静止按需重绘。

**原生 DOM/CSS**：资源 HUD、结束回合、城市/队列、研究/科技、单位详情、战斗预览、设置、帮助、调试抽屉和文本事件。面板使用语义按钮、表单、标签、滚动与焦点能力，不在 Canvas 自绘文字控件。

**边界**：权威规则与观察投影不进入样式层；渲染只消费合法范围和可见事件。Canvas 像素坐标与 DOM 面板不共享隐式状态，选中对象通过明确 ID 和观察快照同步。
