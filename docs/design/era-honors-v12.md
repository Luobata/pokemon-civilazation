# 世代荣誉 v12（对应《文明 6》黄金时代 / 黑暗时代）

- 状态：实现规格，对应 `docs/design/civ6-gap-roadmap.md` §2「时代（黄金/黑暗时代）+ 时代分」P1、`districts-v10.md` 附录 P1 第 2 项。
- 版本：`gameplayVersion: 12`，累积包含 v1–v11。v≤11 的存档、命令日志和回放逐字节不变。

## 1. 玩家看到的规则

- 每个文明在**当前世代**里累积**世代分**。完成科技进入下一个世代时，按上一个世代的表现决定新世代是哪一种：
  - **黄金世代**：上一世代平均每轮得分 ≥ 黄金线；
  - **黑暗世代**：低于黑暗线；
  - **普通世代**：介于两者之间。
- 用“平均每轮得分”而不是总分，是因为精简进程每个世代很长、完整进程有的世代很短，总分不可比。上一世代少于 4 轮时直接进入普通世代。开局第一个世代总是普通世代。

### 效果（持续整个世代）

| 世代 | 效果 |
| --- | --- |
| 黄金世代 | 每座城市金币 +1；满意度每轮 +3；规章点每轮 +2 |
| 黑暗世代 | 满意度每轮 −2；但“逆境”：训练宝可梦所需生产 −20%，所有宝可梦每轮额外恢复 3 HP |
| 普通世代 | 无 |

黑暗世代不是纯惩罚：满意度更容易掉到 20 以下、城市羁绊承压，但练兵更快，给落后文明一个翻盘手段。

## 2. 设计理由

- 只用已有事件计分，不新建资源；效果复用方针效果键、满意度和规章点，所有预览自动一致。
- 不需要新命令：世代类型由过去的行动决定，玩家能做的是“这个世代多完成里程碑”。时代页面实时显示本世代得分、平均速度和两条线。
- 阈值按模拟校准（见 §4），让黄金、黑暗世代都常见但不是默认。

## 3. AI

无新决策。AI 本来就会建城、捕捉、进化、确立规章，这些自然计分。

## 4. 验收

- v11 固定 48 局改动前后逐文件一致。
- v12 固定 48 局全部正常结束、0 规则错误、两次运行逐字节一致；世代转换中黄金、黑暗各占 15%–40%。
- 结束方式和平均结束轮次相对 v11 变化 ≤ 20 个百分点 / ≤ 10 轮。

## 5. 校准结果（2026-11-04）

- 阈值：黄金线 0.8 分/轮，黑暗线 0.45 分/轮（初版 0.9 / 0.35 时简单时代黄金 13%、黑暗 4%，不达标）。
- v11 固定 48 局改动前后 49/49 文件一致；v12 两次运行 49/49 一致；48 局全部正常结束，0 异常，拒绝仅为已有的迷雾选址 4 次。
- 世代转换占比：简单时代 298 次，普通 61% / 黄金 22% / 黑暗 17%；完整时代（24 局）538 次，普通 40% / 黄金 33% / 黑暗 27%。
- 结束方式相对 v11 最大变化 6.2 个百分点（积分 −6.2、信仰 +6.2）；平均结束轮次 91.1 → 89.6。
