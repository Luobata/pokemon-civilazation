# 移动力与回合反馈 v16

- 状态：已实现。依据用户 2026-11-04 试玩反馈：“开局只有一只妙蛙种子，怎么建城扩张”“回到首都就不能攻击了，和原作不一样”“研究、生产完成没有提示”“加一些音效和背景音乐”。
- 版本：`gameplayVersion: 16`（schema 11，`rulesVersion: 'movement-v16'`），累积包含 v1–v15。v≤15 的存档、命令日志和回放逐字节不变。

## 规则

- **移动力（同《文明》）**：单位每轮的移动力 = 物种移动 + 领袖战术 + 「疾行」。走进一格按地形花费（草原、荒漠、海洋 1；森林、山地、雪原、火山 2；幽灵系处处 1），记在 `movesSpent`。还有移动力时可以继续移动，也可以攻击、捕捉、进化、施工等；这些动作结束本轮。移动力用尽，或停在交战敌方近战/快速单位的控制区内（按到达后的视野判断，事先没看到的敌人也算），本轮结束。轮末清空。
- **开局开拓队**：v≤15 开拓队与首都同格，被城市图标盖住，玩家以为没有开拓队。v16 起开拓队放在首都相邻格（`initialUnitPosition`，不消耗随机数）。

## 界面（所有版本）

- 单位面板显示“移动 剩余/总数”（v16）；单位用完行动后自动选中最近的待命单位（v16）。
- 提醒条新增“开拓队：去建新城”，点击选中开拓队并说明建城条件；“开拓队有危险”保持不变。
- 通知：研究完成、建筑/设施区/训练完成、单位等待出场、建城、人口增减、图鉴发现、新世代、晋升、传说线索、他人建成奇观、奇观被抢、被宣战、停战提议、文明出局，弹出可点击的提示（选择研究 / 选择生产 / 选中单位 / 打开对应页面），7 秒后自动消失，最多 4 条。
- 声音：原创 Web Audio 合成（不使用任何现有曲目或素材）。三首循环音乐（和平探索、战争、菜单），交战时自动切换战争音乐；19 种音效对应移动、攻击、击倒、捕捉、进化、建城、生产、研究、回合、宣战、停战、晋升、奇观、错误等。游戏菜单里可以静音、分别调节音乐和音效音量（保存在本机）。浏览器要求先点击一次页面才会出声。
