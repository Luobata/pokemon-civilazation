# 宝可梦城镇与经典领袖

2026-11-01，按当前产品方向加入经典人物领袖。本文更新 extension-design.md 的 D23「原作训练家保留未来备选」方向；原始设计记录保留。

## 城镇设施

建筑沿用原有 ID、成本、科技门槛及数值。主题名与像素建筑美术同时更新，入口仍按所选城市和设施显示。

| ID | 显示名 | 现有用途 |
| --- | --- | --- |
| headquarters | 联盟总部 | 开拓队入口；失守仍触发文明淘汰 |
| pasture | 树果园 | 食物 +2；工作地块入口 |
| workshop | 精灵球工坊 | 生产 +2；建筑生产入口，不免费产球 |
| meetingHall | 友好商店 | 金币 +2；精灵球采购入口 |
| observatory | 宝可梦研究所 | 科研 +2；研究入口 |
| trainingGround | 宝可梦中心 | 新训练单位经验 +20；训练入口及已有休养信息 |

建筑换装本身不增加治疗按钮、恢复加速或休养前置条件。地图通用小镇造型不表示任何具体设施已经建成，也不暴露敌方隐藏建筑。

## 首批领袖与被动技能

领袖与御三家独立选择。技能随领袖固定，不作为地图单位，不具有额外血量或被俘规则。人类与 AI 使用相同规则。

| 人物 | 技能 | 实际效果 |
| --- | --- | --- |
| 大木博士 | 图鉴研究 | 每座城市每轮科研 +1；建有宝可梦研究所时额外 +1 |
| 渡 | 冠军号令 | 宝可梦主动攻击单位或城市时伤害倍率 ×1.10，反击不享受 |
| 君莎小姐 | 联盟警戒 | 城市视野半径从 2 格增至 3 格；城市反击攻击力 +4 |
| 乔伊小姐 | 悉心护理 | 领地内宝可梦每轮额外恢复 5 HP；击倒时的休养轮数减少 1，至少 1 轮 |

数值是可试玩初版，不代表完成长期平衡验证。各技能的边界：

- 大木博士的加成进入真实科研结算；中立城市及刚占领当轮停产的城市不享受。
- 渡的倍率与已有科技、愤怒倍率进入同一伤害公式，最终统一向下取整；属性免疫仍为零伤害，反击保持原有数值。攻击预览和实际结算读取同一技能。
- 君莎小姐的视野只扩展己方城市周围可见范围，不读取隐藏敌军。杰尼龟的反击攻击力 34 可与技能相加至 38。
- 乔伊小姐的恢复仍遵守原有领地范围、HP 上限、部署顺序与阻塞重试。普通恢复 5 变为 10，医学科技的 10 变为 15；主动战斗击倒的休养 3 变为 2，野生阶段击倒的 2 变为 1。无需先建宝可梦中心。
- 御三家原有羁绊保留：妙蛙种子食物倍率、小火龙战斗经验倍率、杰尼龟城市反击攻击力。小火龙不是伤害加成。

## 兼容与展示

`GameSetup` 与 `PlayerState` 增加可选 `leaderId`，新局选择写入设置、状态、存档与命令日志。未包含此字段的旧存档继续使用原规则，不自动补领袖、不更改 RNG、不重写历史命令；目前沿用 schemaVersion 4 / rulesVersion m5-v1 的兼容扩展。导入会校验领袖 ID 及设置与状态的一致性。

UI 从公共领袖定义读取技能文案，分别展示「下局领袖选择」与「本局当前领袖」。更换选择只有点击新游戏后生效。外交仅公开领袖身份及其固定技能，不公开敌方经济或隐藏单位。
