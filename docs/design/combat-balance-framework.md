# B2：战斗数值内部平衡框架

> 目的：在 B1 的方案 A/B 之后，用同一套可复算指标调整物种，而不是零散拍数值。本文是分析工具与候选补丁，不修改 GDD，不宣称候选已通过 AI 对局平衡验收。

## 1. 两套关系必须分开

**定位关系**回答“谁能接敌、能否反击、适合攻击什么目标”；**属性克制**回答“这一击伤害倍率是多少”。本框架先在中性属性 `E=100`、中性地形 `T=100` 下比较定位，再单独跑属性全对全，避免把两类优势混成一个不可解释的“战力分”。

定位不是额外伤害加成表。下列优势是设计倾向，由现有移动力、射程、反击、地形通行、视野和攻城倍率实现；除这些机制外，不新增“近战对高速 ×120”之类乘区。

| 定位 | 战场职能 | 预期优势对象 | 预期劣势对象 | 实现机制 |
|---|---|---|---|---|
| 近战 | 前排接敌、持续交换、保护后排 | 高速：贴身后可稳定反击，靠 HP/D 拖长交换 | 远程：接近前先承受一轮或数轮输出 | 通常射程1；较高 HP/D；双方射程1时正常反击 |
| 远程 | 后排输出、风筝近战 | 近战：从距离2攻击时近战不能反击 | 高速：更快贴身，失去距离优势；飞行可跨地形接近 | 射程2；攻击方射程大于防守方时免反击 |
| 高速 | 突袭、追击、切断后排 | 远程：移动力4–5对通常3，先缩短距离 | 近战：近身交换没有射程收益，耐久不足时被迫休养 | 移动力4–5、射程1；先手价值来自接敌而非额外伤害 |
| 攻城 | 对城破防、拆除高 HP 目标 | 城市和守城部队；隆隆岩射程3进一步提供安全距离 | 高速：移动2容易被追上；野外机动战输出成本比偏低 | 射程2–3；投石改装后对城 ×1500；城市反击独立计算 |
| 侦察 | 开图、预警、找野生和开拓路线 | 不直接克制战斗定位；优势对象是迷雾、后勤和未发现的落单目标 | 正面交战时通常缺少预算与射程优势 | 视野3、移动4；飞行侦察另有地形通行；不把视野折算成虚假伤害 |
| 水系 | 海域控制、海岸封锁、跨海作战 | 海域中的陆地单位与海岸目标；利用水域通行限制 | 陆上远程隔岸输出；电属性劣势属于另一套体系 | 海洋通行、移动3–4；陆地通行能力按物种而非“水属性”决定 |
| 飞行 | 跨地形机动、后期多线支援 | 攻城和慢速后排：跨越山地/海洋/火山接近 | 同阶远程的持续输出；岩石/电属性关系另行结算 | 移动4–5、视野3、全地形通行；不忽略地形移动消耗 |
| 开拓队（后勤） | 建城、扩张、护送 | 无战斗优势；价值是城市与经济 | 所有交战单位 | HP30、移动2、无反击；被击倒直接移除而非休养 |

“高速克远程、近战克高速、远程克近战”因此是软循环：高速能先接敌，但不免反击；近战能赢耐久交换，却不能阻止远程先手；远程有免反击窗口，却不能让高速永远不可达。水系/飞行主要改变可达性，侦察主要改变信息，攻城主要改变目标类型，不应硬塞进同一个三角。

### 叠加与秒杀约束

1. 单次伤害仍只有 GDD §3.7 的 `A/P/E/T/R/D` 公式。定位不新增 E，属性也不改变移动力或射程。
2. 属性免疫先使伤害为0，不能被“定位优势”改成最小1；非免疫才走最小1。
3. 射程决定反击窗口，地形决定通行和 T，二者与属性 E 分步计算。
4. D15 用等阶最坏组合 `E=220、T=120、R=100` 检查单击 ≤最大 HP 60%。任何定位调整都不能用多段理论模型绕过这条单击硬约束。
5. 交换比模型使用 `E=100、T=100`，只评估定位；属性 D15 另算，不把中性交换比解释为实际每局胜率。

## 2. 可计算的性价比指标

### 2.1 精确规则量

训练成本和维护：

```text
B = HP + A + D
C = floor(B / 8)
U10 = 10 × upkeep
```

`B` 必须落在基础150–170、一阶210–240、二阶280–320。`C` 是生产，`U10` 是金币，两种资源不相加伪装成统一真实成本。需要比较长期持有时，分别报告 `C` 与 `U10`；若要自定义“1生产=若干金币”的权重，必须另列敏感性，不在本表暗中指定汇率。

单次伤害：

```text
hit(A,D,P,E,T,R) = E=0 ? 0 : max(1, floor(A×P×E×T×R / (D×1,000,000)))
```

普通攻击 `P=10`，反击 `P=5、R=100`。期望输出对16个整数随机值逐一枚举，不用 92.5 代入后再取整：

```text
ED(i,j) = Σ[R=85..100] hit(Ai,Dj,10,E,T,R) / 16
```

脚本保留每次整数伤害与16项总和，表格只在展示时保留两位小数。

### 2.2 有效 HP 与成本归一化

每阶段取所有物种防御中位数 `Dref`：基础52、一阶70、二阶92。有效 HP 是相对比较量，不是新增战斗血量：

```text
EHP_i = 1000 × HP_i × D_i / Dref(stage_i)
EHP/C_i = EHP_i / C_i
Output/C_i = (Σ[R=85..100] hit(A_i,Dref,10,100,100,R)) × 1000 / (16 × C_i)
Composite_i = sqrt(EHP/C_i × Output/C_i)
```

`Composite` 只用于同阶段、同定位筛查；高Composite不代表视野、通行、稀有度或进化价值已被定价。

### 2.3 交换比、免反击和移动先手

先算中性场景的一击与反击：

```text
H = hit(Ai,Dj,10,100,100,100)
K = H >= HPj 或 range_i > range_j ? 0 : hit(Aj,Di,5,100,100,100)
X_raw(i,j) = 1000 × H / max(1,K)
```

这条精确复用“防守方存活且攻击方在其射程内才反击”。随后才加入一个**明确用于规划的移动先手系数**，不是游戏规则：

```text
tempo = clamp((move_i + range_i) - (move_j + range_j), -2, +2)
X_tempo = X_raw × (1000 + 100 × tempo) / 1000
```

即移动+射程每多1，交换估值±10%，最多±20%。它用于区分“能否先接敌”，不声称移动在 core 里直接增加伤害。每只物种报告对同阶其他物种的 `X_tempo` 中位数；完整39×39结果和对七类同阶定位中位 archetype 的结果在 JSON 中。

### 2.4 离群判定

- 同阶段、同定位且组内 `N>=3`：`EHP/C`、`Output/C`、`Composite`、`X_tempo中位数`相对组中位数 `>=1.25` 或 `<=0.75` 标为离群。
- `N<3` 只列观察，不凭一两个物种宣布定位过强/过弱。
- 定位系统偏差看同一定位全部阶段的均值，并同时检查维护、视野、通行和稀有度；不只用交换比下结论。
- 候选修改后必须重新跑39种预算/成本与D15；对局影响仍需A/B模拟，指标改善不等于胜率达标。

- **远程对近战存在系统性射程溢价**：两者Output/C接近（381.20对392.80），远程交换比均值却约为近战2.68倍。主要不是攻击高，而是射程2对射程1的免反击。优先补近战耐久或接敌能力，不宜再普遍加近战攻击。
- **攻城是高耐久、低持续输出、特殊目标定位**：EHP/C最高，Output/C仅高于水系/飞行，射程使其交换比高。大岩蛇EHP/C3666.67、Output/C247.92是明显坦克方向，但组内N=2，不列为正式离群或直接削弱。

- **水系数值受通行限制**：不能拿海洋专属与陆地单位只比交换比；海域图比例是后续模拟必须报告的维度。

### 4.4 对征服与性格的假设（不是结果）

- 近战耐久提高，**假设**好战型接敌后休养减少、持续推进更稳定，可能提高征服并改善好战配对；但成本提高可能推迟达到3单位门槛，必须同时看首次军力轮数。
- 杰尼龟耐久下降，**假设**基础远程开局不再过度耐打，可能加快早期交战；其城市反击加成不变，不预期直接改变城市HP节奏。
- 快龙爆发和移动下降，**假设**后期飞行的滚雪球与多线推进减弱；HP提高使其更偏坦克，需观察是否反而延长对局。
- 这些修改不直接调整城市HP、城市计分或AI性格，不应被用来替代B1的A/B验证。

### 4.5 补丁不支持的调整

当前候选全部受支持，无缺失字段。若后续要新增“近战对远程减伤”“定位专属维护曲线”“按定位解锁射程/移动”或“攻城对兵种额外倍率”，这些属于规则结构或新行为开关，现有patch不支持，必须先写GDD/技术提案，不能塞进物种JSON冒充数值调整。P保持10、属性/免疫/角色与通行表不在本候选修改。

## 5. 与B1方案A/B的衔接

按以下顺序继续，避免用物种修正掩盖城市或AI问题：

1. **先读完A/B同种子结果**：若征服仍低且每次占城攻击段仍长，先用城市HP/攻城杠杆；若好战仍无法达到军力或扩张门槛，先用AI门槛。不要为了提升征服直接全面提高物种A。
2. **性格配对仍失衡但推进机制正常**：先拆分城市计分、维护与物种交换的贡献。扩张仍靠城市分领先时，不加强其通用兵种。
3. **内部模型有明确离群时**：先分别跑杰尼龟、快龙单物种补丁，再跑近战包；近战包内部按基础/一阶/二阶分组消融。本文合并D15通过不等于允许一次性全部正式采用。
4. **每轮都复查**：39预算/成本、D15全对全、同种子A/B、D18追加样本，以及征服、1v3轮数、三组配对、先手、滚雪球、捕捉和攻城/军力漏斗。任一原达标项退化都停止叠加修改。

如果A/B后仍未达标，优先级是：**先确认是城市/AI问题还是物种问题 → 再动城市或AI对应杠杆 → 最后才用本框架的离群物种补丁**。轮上限按D40保持100，不用延长轮数替代内部平衡。
