# 特性晋升 v13（对应《文明 6》单位晋升）

- 状态：实现规格，对应 `docs/design/civ6-gap-roadmap.md` §2「晋升树」P1、`districts-v10.md` 附录 P1 第 3 项。
- 版本：`gameplayVersion: 13`，累积包含 v1–v12。v≤12 的存档、命令日志和回放逐字节不变。

## 1. 玩家看到的规则

- 宝可梦在战斗中累积**战功**（和进化用的经验分开，进化不会清空战功）：

| 行为 | 战功 |
| --- | --- |
| 主动攻击并造成伤害 | +2 |
| 反击并造成伤害 | +1 |
| 击倒一个单位 | +3 |
| 攻下一座城市 | +3 |

- 战功达到 **6 / 14 / 24** 时各获得一次晋升机会，最多 3 次。每次从下面 5 个**特性**里选一个，不能重复。选择不消耗行动。

| 特性 | 效果 |
| --- | --- |
| 破城 | 攻击城市伤害 +25% |
| 猛攻 | 主动攻击宝可梦伤害 +15% |
| 坚守 | 受到宝可梦的伤害 −15%（包括被攻击和吃反击） |
| 疾行 | 移动力 +1 |
| 再生 | 每轮额外恢复 5 HP，在哪里都生效 |

- 特性对其他玩家公开：看得见的敌方单位，地块信息里会列出它的特性；战斗预览会算进双方的特性。

## 2. 设计理由

- 只用战斗事件计战功，不算领地内每轮的亲密度经验，避免待在家里的宝可梦也自动晋升。
- 与进化分开：进化是“换物种”，晋升是“同一只宝可梦的专长”，两者都保留，老兵更值钱，也让“保护受伤老兵”成为决策。
- 五个特性分别对应攻城、野战、防守、机动、续航，和兵种定位（攻城 / 近战 / 远程 / 快速 / 侦察）搭配。
- 数值都是乘在已有伤害链上的倍率，战斗预览与权威结算共用同一份计算。

## 3. AI

- 有晋升机会时立即选择（不消耗行动，按单位 ID 从小到大）：攻城型优先破城，近战、快速、飞行优先猛攻，远程优先坚守，侦察优先疾行，水面优先再生；已选的跳过，按每个定位的固定顺序补选（见 `src/core/promotions.ts` ROLE_ORDER）。
- 晋升事件只通知单位所属玩家；其他玩家通过视野内单位的特性看到结果，不会因为事件得知看不见的单位。

## 4. 验收

- v12 固定 48 局改动前后逐文件一致。
- v13 固定 48 局全部正常结束、0 规则错误、两次运行逐字节一致；统计晋升次数与各特性占比，每局都有晋升，单一特性占比 ≤ 60%。
- 预览一致性：真实对局中抽样所有“可攻击”目标，预览伤害区间与权威结算一致（沿用已有的预览测试方式）。
- 结束方式和平均结束轮次相对 v12 变化 ≤ 20 个百分点 / ≤ 10 轮。

## 5. 实现与验收结果（2026-11-04）

- 评审后的调整：野生宝可梦或守卫发起的战斗不给战功（避免守在巢穴旁的单位被动晋升）；其他玩家只看得到特性、看不到战功；只有在地图上的单位能晋升，恢复中的单位回到地图后再选（玩家和 AI 一致）。
- v12 固定 48 局改动前后 49/49 文件一致；v13 两次运行 49/49 一致；48 局全部正常结束，0 异常、0 规则错误，拒绝仅为已有的迷雾选址 3 次。
- 晋升 2107 次，每局 10–90 次（中位 45），没有不晋升的对局。特性占比：坚守 36%、猛攻 29%、再生 25%、破城 8%、疾行 3%。
- 结束方式相对 v12 最大变化 10.4 个百分点（信仰 6→1，征服 6→8，积分 22→24）；平均结束轮次 89.6 → 89.2。
- 预览一致性：评审时用 1728 次真实攻击（12×12 近战组合 × 3 种特性组合 × 4 个随机种子）核对，伤害都在预览区间内，反击与预览完全相等。
- 同批修复：树果赠送 AI 不知道自己的赠送冷却，会发出被拒命令并提前结束回合；现在视图带上自己的赠送记录，AI 跳过冷却中的对象。
