# 世界扩展系统设计（S18–S22）

本文对应 opt-in 扩展 `expansionVersion: 1` 中的世界层。该层只挂在 `GameState.expansion.world`；未开启扩展的旧规则、存档与回放不会创建世界状态，也不会消耗随机数。实现位于：

- 运行时：`src/core/world-systems.ts`
- 内容与数值：`src/content/world-systems.ts`
- 引擎测试：`tests/core/world-systems.test.ts`

## 1. 设计目标

S18–S22 不是审计页里的静态描述，而是可执行的大地图玩法：

- **S18 暴走宝可梦与巢穴**：巢穴周期性生成主动袭击单位和城市的敌对野生宝可梦；玩家可多次清剿，清空后获得有限奖励。
- **S19 霸主领地**：地图上存在唯一中立霸主。附近城市用食物或金币供奉，提升羁绊等级并获得视野与本地产出。
- **S20 树果**：树果是可消耗、可再生地块资源。单位站在资源格收获，附近城市获得食物，文明获得满意度；被城市工作的资源格也有基础产出加成。
- **S21 进化石**：地图矿脉一次性产出进化石；特定进化必须消耗对应石头、满足经验阈值并占用单位本回合行动。
- **S22 图鉴收集与图鉴胜利**：每名玩家独立记录观察到、战斗过和捕捉过的物种。达到 18 种“已观察且战斗或捕捉”的完整记录后，该玩家获得图鉴胜利。

所有随机决策共用 `GameState.rng`，调用顺序由初始化、回合结算和事件目标排序固定。同种子、同命令、同内容得到相同状态。

## 2. 权威状态

```ts
type WorldState = {
  version: 'world-v1';
  initializedAtRound: number;
  nests: Record<number, NestSite>;
  rampagingUnitIds: number[];
  overlords: Record<number, OverlordSite>;
  resources: Record<number, ResourceSite>;
  players: Record<number, WorldPlayerState>;
  victory: WorldVictoryState;
};
```

每名玩家的满意度、树果库存、进化石库存和图鉴保存在 `players[playerId]`，没有全局共享图鉴。初始已登记的御三家只写入该玩家自己的“观察 + 捕捉”记录。

世界实体在开局由 `state.rng` 从合法地块抽样放置：

- 6 个巢穴，距离任一城市至少 4 格；
- 3 个霸主，距离任一城市至少 5 格；
- 10 个树果资源；
- 每种进化石 2 处矿脉，共 10 处。

巢穴会优先从新增的地面、毒、虫、冰、电/钢、恶、妖精代表物种中选择能适应该群系的物种，使扩展生态进入图鉴与暴走玩法；这些新增物种的旧模式 `spawnBiomes` 仍为空，不改变旧模式随机流。

## 3. 命令

```ts
type WorldAction =
  | { type: 'ClearNest'; unitId: number; nestId: number }
  | { type: 'OfferToOverlord'; overlordId: number; cityId: number; currency: 'food' | 'gold' }
  | { type: 'HarvestResource'; unitId: number; tileIndex: number }
  | { type: 'UseEvolutionStone'; unitId: number; intoSpeciesId: SpeciesId; stoneId: StoneId };
```

所有命令先验证后应用。验证失败不改变 RNG、实体 ID 或状态；成功命令仍由共享 `step` 在完整克隆状态上提交。

### 3.1 清剿巢穴

巢穴 HP 52。攻击方每次造成 `max(3, floor(攻击 / 3))` 伤害，并受到巢穴反击 8 点伤害；单位 HP 最低保留 1，避免清剿奖励变成自杀命令。行动消耗 1 点，通常需要 3–5 次有效攻击。巢穴清空后删除实体，奖励 24 金币和 10 满意度，只发放一次。

### 3.2 供奉霸主

每个霸主对每名玩家维护独立羁绊和供奉轮次。城市中心距离霸主 3 格内才可供奉，同一玩家对同一霸主每轮一次：

- 10 食物或 20 金币；
- 羁绊 +5；
- 15 / 40 / 75 点分别达到 1 / 2 / 3 级。

等级效果为：

1. 以霸主为中心获得半径 2 视野；
2. 范围内城市获得 `+1 食物 / +1 生产 / +1 金币`；
3. 范围内城市获得 `+1 食物 / +1 生产 / +2 金币 / +1 科研`。

同城市多个霸主只取最高等级，不叠乘或叠加。

### 3.3 收获树果与进化石

单位必须位于资源格且还有行动点。树果必须距离一座己方城市 3 格内；每次收获：

- 城市立即获得该树果的食物值；
- 玩家库存 +1；
- 满意度按树果定义增加；
- 资源使用次数减 1，并在 5–8 轮后再生。

树果定义：

| 树果 | 食物 | 满意度 | 次数 | 再生轮数 |
|---|---:|---:|---:|---:|
| 橙果 | 8 | 10 | 3 | 5 |
| 文柚果 | 12 | 14 | 2 | 7 |
| 木子果 | 6 | 16 | 2 | 8 |
| 蕉香果 | 10 | 12 | 3 | 6 |

被城市工作的树果格提供 `floor(树果食物 / 4)` 食物；进化石矿脉提供 +1 生产。矿脉一次性产出 1 枚石头，不再生。

满意度每轮衰减 4，上限 100。达到 50 或以上时该玩家每轮获得 2 金币。清剿巢穴与收获树果是主要恢复来源。

### 3.4 进化石进化

扩展内容定义五条显式进化合同：

- 皮卡丘 —雷之石→ 雷丘，100 XP；
- 妙蛙草 —叶之石→ 妙蛙花，250 XP；
- 火恐龙 —火之石→ 喷火龙，250 XP；
- 卡咪龟 —水之石→ 水箭龟，250 XP；
- 皮皮 —月之石→ 皮可西，100 XP。

石头必须来自实际矿脉收获。命令消耗 1 枚石头和 1 点行动；HP 按新旧最大 HP 等比保留，XP 归零，进化解锁登记到旧的经济物种注册表和该玩家图鉴。

## 4. 每轮世界结算

`resolveWorldRound` 在完整轮结束阶段执行，顺序固定：

1. 清理已死亡或已转属的暴走单位；
2. 到轮次的巢穴尝试生成 1 只 80% HP 的敌对野生单位；每个巢穴最多 3 只，生成间隔 6 轮；
3. 所有暴走单位按距离、目标类型和实体 ID 稳定选择最近目标，先攻击或向目标移动一格；
4. 清理战斗死亡单位；
5. 到期树果再生；
6. 每名玩家结算满意度衰减与繁荣金币；
7. 共享记录钩子根据事件和可见性更新图鉴。

对单位的暴走攻击复用现有战斗结算，包括反击、经验、濒死撤退和 RNG。对城市的攻击使用现有攻城伤害公式，但城市 HP 最低保留 1，不会触发占领、霸主归属变化或文明淘汰；这避免让中立野生单位执行只有文明单位才能安全完成的城市所有权转移。

## 5. 图鉴、迷雾与胜利

图鉴记录三类事实：

- `observed`：单位或事件路径在玩家有效视野内；
- `battled`：战斗事件所有位置对该玩家可见，战斗双方物种均记录；
- `captured`：该玩家捕捉成功，或通过本玩家单位进化登记。

`observed && (battled || captured)` 视为一条完整记录。任一玩家首次达到 18 条时：

1. 写入该玩家的 `WorldVictoryAchieved` 事件；
2. 调用共享 `finishGame(state, 'pokedex', [playerId], content)`；
3. 产生正常 `GameEnded` 事件，排名使用当前内容配置。

战斗事件采用与旧事件投影一致的“所有位置均可见”判定，防止只看到己方攻击端时泄露迷雾外防守物种。`observeWorld` 只投影：

- 可见巢穴、霸主和资源；
- 可见暴走单位 ID；
- 调用者自己的库存与图鉴；
- 全局胜利目标与完成轮次。

霸主羁绊视野通过 `worldVisionSources(state, playerId)` 提供给共享视野系统，因此命令验证、观察和历史记忆使用同一边界。

## 6. AI 与集成接口

`planWorldAction(view, content)` 基于玩家可见视图选择真实命令，优先级为：

1. 可射击巢穴的清剿；
2. 当前资源格上的收获；
3. 可负担且未在本轮供奉的霸主；
4. 满足 XP 与库存的进化石进化。

返回值是标准 `WorldAction` 或 `null`，不伪造未来信息。共享经济通过 `worldCityYield(state, city, content)` 合并资源格与霸主收益。

世界事件只使用 `World...` 前缀变体。暴走攻击复用的 `BattleResolved` / `Moved` 仍作为基础事件返回，由共享事件管线处理索引、投影和迷雾过滤。

## 7. 验证

`tests/core/world-systems.test.ts` 覆盖 11 个行为：

1. 开局实体数量、位置与物种确定性；
2. 图鉴初始记录按玩家隔离；
3. 世界命令类型守卫；
4. 巢穴多击清剿、反击、行动消耗和一次性奖励；
5. 巢穴生成与暴走主动攻城，城市不会被中立单位占领；
6. 树果收获、城市食物、满意度、库存与再生；
7. 进化石消耗、行动消耗、HP 缩放、XP 重置与图鉴登记；
8. 霸主供奉、每轮一次限制、视野来源与本地收益；
9. 战斗另一端在迷雾外时不泄露物种，且玩家记录独立；
10. 18 条完整图鉴记录触发单人 pokedex 胜利；
11. 世界观察只暴露可见站点和调用者账簿，AI 计划只返回可执行命令。

当前专项验证：`npx vitest run tests/core/world-systems.test.ts`，11/11 通过；三个新增源/测试文件 ESLint 通过。共享构建等待所有扩展模块与根集成完成后统一执行。
