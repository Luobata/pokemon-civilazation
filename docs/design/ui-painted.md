# 绘卷画风：插画地图与界面改造（ui-painted）

2026-11-20 · 用户反馈：“当前 2.5D 的感觉不是很喜欢，可以参考文明 6 的画风，单独做一版 UI 改造。”

目标是在现有的平面像素地图（默认）和 2.5D 像素原型之外，做**第三套画风**，叫“**绘卷**”：插画式的地形、轻微倾斜的地图、柔和圆润的起伏、温暖饱和略带风格化的颜色、羊皮纸与墨线的“探险家地图”迷雾、带金属装饰的界面框、圆形图标徽章、大头像和阵营色旗帜。平面和 2.5D 两种像素模式原样保留，作为可选项。

- 打开方式：`?theme=painted`（别名 `?theme=atlas`），或 菜单 → **画风** → 绘卷（插画）。选择存在本浏览器的 `localStorage`（`pokeciv.theme`），`?theme=pixel` 可临时切回像素。选“绘卷”时“地图视角”（平面 / 2.5D）变灰，切回“像素”时恢复原来的地图视角。联机页读取同一个设置。
- 原型截图见 `docs/design/ui-painted/`，同一画面的平面像素版本放在旁边对比（文件名 `painted-*` / `flat-*`）。

**原创约束**：只借用这一类游戏的通用气质（插画地形、倾斜视角、柔和光影、羊皮纸迷雾、金属边框、圆形徽章），不复制、描摹或重建任何《文明 6》的素材、图标、字体、界面布局、边框图案、精确配色或画面。本画风的主色是“胡桃木 + 黄铜 + 羊皮纸 + 青瓷釉”，有意避开原作的深蓝金配色；所有地形、物件、城镇、徽章、边框都是本项目用代码画出的原创图形；装饰母题是原创的“捕获球式”小圆饰（黄铜圈、上半青瓷釉、下半米色、中间一道暗带和圆钮）。宝可梦物种精灵继续使用 `public/sprites/` 里现有的图。

## 1. 素材方案

| | A. 程序化插画贴图（推荐，已实现） | B. 手绘矢量 SVG，光栅化进缓存 |
| --- | --- | --- |
| 做法 | 运行时用 Canvas 2D 在离屏画布上画：线性 / 径向渐变打底，十几个柔边色斑（径向渐变的“笔触”），短弧线笔触（草、沙丘、浪），再把边缘做羽化；物件（树、山、丘、火山、城镇、徽章）同样用渐变和曲线画 | 美术在矢量工具里画每种地块、物件、城镇的 SVG，打包进 `public/`，运行时 `Image` 解码后 `drawImage` 进缓存 |
| 分辨率与 DPR | 按“设备像素半径”的四分之一倍频档位烘焙（`kit.ts` 的 `bucket`），绘制时平滑缩放到准确尺寸（误差 ≤ 9%，插画风格看不出）；DPR 1 / 2 各自一套 | SVG 本身无级缩放，但每个档位仍要光栅化一次；首次解码有异步延迟，需要占位 |
| 变化 | 每种生物群系 4 个变体，用种子噪声，零额外体积；改颜色、密度是改常数 | 每个变体都是一张美术稿，变体越多体积越大 |
| 一致性 | 光照方向、描边粗细、色板都在代码里统一 | 依赖美术自律；不同人画的风格容易不齐 |
| 体积 / 加载 | 0 KB 资源；首次进入某个缩放档位时烘焙 ~40 张小图（约 50–150 ms，只发生一次，之后命中缓存） | 每套 30–80 KB SVG；要预加载 |
| 适合 | 地形底图、羽化、迷雾墨线、旗帜框、产出硬币 | 需要精细造型的“英雄”素材：大头像、奇观、领袖立绘 |

**推荐 A 作为主体**，B 留给以后可能的少量英雄素材（奇观插画、领袖立绘），两者走同一个缓存接口（`spriteCache`），所以可以逐个替换。理由：零资源体积、所有变体和档位都由同一套光照和色板生成、和现有的“代码画图”管线（`map-icons.ts`、`terrain25d.ts`）一致，也最容易满足“原创”约束（没有任何外部素材）。

缓存（全部在 `src/browser/render/painted/`）：

| 缓存 | 键 | 上限 |
| --- | --- | --- |
| 地面贴图 `groundSprite` | 种类（7 生物群系 + 浅海 / 深海 / 湖 / 未探索）× 变体 × 半径档位 × 俯角 | 160 |
| 物件 `propSprite` | 生物群系 × 变体 × 丘陵 × 高峰 × 档位 × 俯角 | 220 |
| 迷雾墨线 `inkGlyph` | 种类 × 丘陵 × 高峰 × 变体 × 档位 | 120 |
| 单位徽章框 `medallionFrame` | 阵营 × 颜色 × 敌对 × 已行动 × 档位 | 96 |
| 属性徽章、产出硬币行 | 属性 / 产出组合 × 档位 | 64 / 240 |
| 城镇 `townSprite`（含夜间窗灯） | 阵营色 × 房子数 × 首都 × 奇观 × 档位 × 俯角 | 64 |

超过上限时整组清空重烘（缩放档位变化很少，烘焙便宜）。

## 2. 地图

### 2.0 投影、拾取、环绕（复用）

- **复用 2.5D 的“压扁世界 y”**（`camera.ts` 的 `setMapTilt`），系数取 **0.8**（`PAINTED_TILT`，约 37°，比 2.5D 的 0.75 更平缓），但**所有地块高度为 0**：起伏靠插画（丘陵的圆顶、山体、阴影）表达，不做柱体和崖壁。
- 因此**拾取就是平面反算**（`worldToHex(toWorld(p))`，压扁已在 `worldToHex` 里处理），`renderer.lift()` 恒为 0，所有覆盖层锚点、聚焦、“定位”、战斗卡都直接正确；不存在 2.5D 的“高峰挡住后面格子”问题。
- 东西环绕：`copyShifts` 照旧；地形块按世界空间切块（复用 `chunks25d.ts`），环绕副本是同一组块的平移。
- 物件（树、山、城镇、旗帜）是竖立的，不压扁；它们的影子和地面形状压扁。

### 2.1 地形（`painted/terrain.ts`）

每种地面贴图：轻微的西北光渐变（故意很弱，避免一格一格的“瓷砖感”）→ 18 个跨出格子的柔边色斑 → 按生物群系的笔触 → 边缘羽化。

| 地形 | 地面 | 物件 |
| --- | --- | --- |
| 草原 | 黄绿，V 形草簇，零星小花 | 圆灌木 1–3 丛，个别变体有孤树 |
| 森林 | 深绿林地 | 7 棵树：三团圆冠的阔叶树（左上受光的径向渐变）为主，三成针叶树；各自带向东南的柔影 |
| 沙漠 | 暖沙色，四道沙丘（亮脊 + 暗背风面），细砂点 | 仙人掌或圆石 |
| 雪原 | 白蓝，蓝灰阴影带，亮白雪纹 | 2–3 棵覆雪针叶树 |
| 山地 | 灰褐碎石 | 三座圆润山体：左亮右暗的渐变，东面阴影，山脊沟壑笔触，小雪顶 |
| 高峰（特征） | — | 高大的雪顶山体（雪顶占一半） |
| 丘陵（特征） | — | 一大一小两座低矮圆顶（径向渐变 + 一道受光的脊线），上面的树随圆顶抬高 |
| 火山 | 玄武岩，橙色熔岩裂纹 | 平顶火山锥：发光火口、熔岩流、三团烟 |
| 海洋 | 蓝，浪花月牙 | — |
| 浅海 | 比海洋略亮的蓝绿；另有沿海岸的“浅滩光” | — |
| 深海 | 深蓝，浪花更淡 | — |
| 湖 | 亮青 | — |
| 地标 | — | 竖立的石碑，顶上是带黄铜圈的彩色徽记（原地标字） |
| 河流 | — | 三层带：暗色河岸、蓝色水面、亮色水心，按随机弯曲的二次曲线从格心流向相连的边 |

**格与格之间的融合**：每张地面贴图在**自己的整个六边形内不透明**，从六边形边缘向外羽化（陆地到 1.32 倍半径，水面到 1.5 倍）。地块按行从后往前画，后画的格子柔和地盖住先画的邻格边缘，所以：没有缝、边缘没有“台阶”、相邻两种地形之间是一条柔和的过渡带。未探索的格子先画，已探索的土地向四周的暗处柔和淡出，而不是一条六边形轮廓。陆地上叠一层很淡的手绘格线（`rgba(40,28,14,.11)`），水面不画格线（大海读作一整片）。

### 2.2 海岸

1. **浅滩光**：沿每条海岸边、只在水面一侧（裁剪到水面格子），叠三层逐渐变窄的浅青色宽线（1.15 / 0.7 / 0.34 倍半径），形成跟着海岸线走的渐变浅滩。
2. **沙滩**：海岸边的陆地一侧一道 0.2 倍半径的沙色带，颜色看相邻陆地（雪原是雪白、火山是黑沙、山地是碎石色）。
3. 一道湿沙线、两道离岸的白色浪花线（第二道更淡更短）。

### 2.3 领土边界：阵营色发光丝带

每条边界边向格心收 9%（两国在同一条边上的丝带并排而不重叠）；内侧是一片从边缘向内淡出的阵营色光晕（线性渐变，0.5 → 0），然后三层描边：深色外缘、阵营色丝带、浅色丝线高光。“发光”全部用叠加描边和渐变实现，**没有 `shadowBlur`**，而且画在地形块里（缓存）。

### 2.4 城市：会长大的插画城镇（`painted/tokens.ts`）

- 一块暖色石板广场（阵营色无关），首都和 8 人口以上的城市有一圈低矮石墙（后半圈在房子后面、前半圈在房子前面）。
- 房子：山墙朝前的小屋（受光的正面、暗侧墙、两面坡屋顶、门窗、檐线），屋顶多为陶红色，每第三座用阵营色。房子数 = 2 + ⌊人口 / 2⌋（最多 11 座），从中心向外排开，按 y 排序遮挡。
- 中心：首都是带垛口的石塔、阵营色尖顶和三角旗；普通城市是阵营色屋顶的议事厅，屋脊上一个阵营色小圆顶（中间一道白带）。有传说奇观时多一座金色穹顶尖塔。
- 夜晚：每座城镇烘焙一张“窗灯”图（每扇窗一团暖光 + 整个城镇的淡光晕），夜色遮罩之后用 `lighter` 叠加，夜里城市是地图上最亮的地方。
- 城市横幅：阵营色丝带（上亮下暗的渐变、黄铜内线、两端燕尾），左端挂一个黄铜圈的阵营圆章（写文明编号，野生是“爪”），然后是米色人口圆章、衬线体城名（深色描边）、首都星、奇观王冠；受损时下面一条圆角血条。选中城市时内线变亮，城镇脚下一圈金色光环。

### 2.5 单位：徽章旗

- 每个单位是一枚“徽章旗”：圆形徽章（阵营色金属圈，左上高光、右下暗，圈上叠色盲安全花纹：文明 2 斜纹、3 圆点、4 交叉纹，与像素版一致），米色内盘里是宝可梦精灵（像素精灵保持清晰，不做平滑缩放），徽章挂在一根短旗杆上，下面两条燕尾彩带，旗杆脚下一个柔影。整枚徽章离地站在格子前部，所以一眼能看出“旗子插在哪一格”。
- 右上角黄铜小圆钮写文明编号（野生“爪”）；右下角是**属性徽章**（属性色圆章 + 原有的 8×8 属性符号）；后勤单位换成金色“拓 / 工 / 商”；左下角“✓”表示已行动（整枚徽章同时褪色）；左上是时代形态（M / 极 / 晶 / Z / 劲），激怒的“!”在左侧；右侧是晋升 V 字和可晋升箭头；受损时徽章下沿一段弧形血条。
- 敌对单位外面多一圈红环。同格的后勤单位画成 0.6 倍的小徽章，放在格子右下。
- 动画（移动、战斗残影、进化白光、极巨化放大）都作用在整枚徽章上；残影的灰度 `filter` 仍只作用于单个单位（与像素版相同，已有的性能约束允许）。

### 2.6 地块产出：小圆硬币

食物（绿底叶子）、生产（橙褐底锤子）、金币（金底钱币）、科研（蓝底烧瓶），每种一枚带深色描边的圆硬币，数值大于 1 时在硬币右边写数字；整行垫一条半透明深色圆角底，在雪地和沙地上也能看清。每种“产出组合 × 尺寸”烘焙成一张图，每格一次 `drawImage`。迷雾格不画产出（城市工作范围内的除外）。

### 2.7 选中与范围

- 移动范围：可达格一层很淡的青色光，外轮廓是“发光青色丝带”（宽而淡的光晕 + 深色衬底 + 青色线 + 白色细芯）。
- 攻击范围：淡红色光 + 红色虚线轮廓。攻击 / 捕捉目标：目标单位徽章外面一圈红（捕捉为琥珀色）虚线环加四个准星刻度，左下角“×”或“球”。
- 选中单位：徽章外一圈金色光环 + 脚下一圈金色地面椭圆。检查中的地块：米白双线六边形；键盘光标：紫色虚线。设施区选址：金色 / 暗红六边形。

### 2.8 迷雾：羊皮纸与墨线（`painted/fog.ts`）

- 已探索但看不见的格子盖上**羊皮纸**（一张 256 px 的原创纸纹：色斑、纤维、斑点，四边环绕无缝），纸纹锚在地图上（跟着地图平移，不会“游动”），按地形轻微着色（海偏灰蓝、森林偏橄榄、雪偏白），让海陆仍然分得清。
- 地形用**褐色墨线**重画：海是两三道波浪线，草原是小草勾，森林是棒棒糖小树，雪原是小三角松树和点，沙漠是两道沙丘弧和点画，山地是带东面排线的山形（高峰加雪线），火山是锥形加一缕烟，丘陵是两道圆弧，河流是一条墨线。
- **海岸**用粗墨线勾出，水面一侧加两道平行的“等深线”涟漪（经典地图画法）。
- **边界**在迷雾里是阵营色虚线。
- 迷雾和“活地图”的交界：一道宽而淡的焦褐色边（像纸边被烤过）+ 一条细墨线。
- 迷雾层画在地形之后、城镇 / 资源 / 设施区之前，所以记得的城镇和资源像是“画在地图上的注记”；单位只出现在可见格，所以不受影响（只读 PlayerView，不泄露信息）。
- 迷雾格的竖立物件不画进地形块（墨线代替）。地形块按块记录“自己和周围一圈”的迷雾签名，单位移动后只重建迷雾变化波及的块。

### 2.9 夜晚和天气

- 夜晚：仍是每帧一次的整图遮罩（深靛蓝 46%），之后叠城镇窗灯。白天 / 夜晚的 1.2 s 渐变（V11）照旧缩放遮罩和窗灯。
- 天气：复用像素版的天气染色和标记（`drawWeather`，六边形按 0.8 压扁）。下一步可以换成柔边的天气云团（见“还差什么”）。

### 2.10 其余覆盖层（复用）

资源 / 巢穴 / 道馆徽章、设施区、改良、施工标记、商路、前往路线、战斗和大事件特效、调试层直接复用 Canvas 2D 后端的图层函数（`canvas2d.ts` 只把这些函数加了 `export`）。资源徽章本来就是圆形徽章，和本画风协调；设施区和改良仍是像素图标，是下一步要换的。

## 3. HUD 与面板（`src/painted.css`）

原则：仍然“图标优先”；**只改颜色、边框、阴影和字体，不改任何面板的位置和尺寸**，所以行动栏、通知栏、开局目标卡、战斗卡都不会被遮挡（与 ui-25d §11 相同的约束）；全部选择器以 `html.theme-painted` 开头，像素画风完全不受影响。

- **框体系**：胡桃木渐变面板，外面一圈深色描边 + 黄铜外线，里面一道黄铜细线和一道暗线（双线黄铜框，全用 0 模糊的 `box-shadow` 实现）；面板下沿两角各一枚原创“捕获球式”小圆饰；标题条是深色皮革，底下双道黄铜线，标题用衬线体、浅黄铜色。
- **顶栏**：皮革色带 + 底部黄铜双线；金币 / 科研 / 维护三个资源各放进一枚**圆形珐琅徽章**（琥珀金、天青、赭红底，黄铜圈）；轮次数字用衬线体；右侧系统入口每个图标是一枚黄铜圈的圆徽章，当前打开的那枚变成青瓷釉。
- **单位面板**：头像放大成 92 px 的**圆形徽章**——米色内盘、属性色内圈、黄铜外圈（属性色沿用 ui-25d 的 `:has()` 读取，不改 TS）；标题条带属性色顶边和渐变；属性数值格是圆角皮革石板，数字衬线体；HP / EXP 条圆角。
- **城市面板**：标题条是**阵营色旗帜**（阵营色渐变 + 黄铜底线），城名衬线体加大，前面一枚圆饰；生产页签按下是黄铜色。
- **研究树**：节点卡片左端做成半圆，图标放进**圆形徽章**（米色内盘、分支色内圈、黄铜外圈）；已完成 / 研究中 / 可研究 / 未解锁分别是绿 / 青光 / 金 / 原样，形状和颜色双重区分；连线改成黄铜色。
- **按钮**：深色皮革 + 黄铜细边；主按钮（下一回合、确认）是青瓷釉圆角，外面一圈黄铜环，“下一回合”再多一圈淡黄铜光环。
- **世界页、通知栏、行动栏、领袖头像**（设计，未全部实现）：世界页卡片用同一套双线黄铜框，卡片标题前加圆饰；通知栏每条通知左侧一枚圆形图标徽章（类型色），保持现在的位置和堆叠方向；行动栏按钮做成圆角皮革键，图标进圆徽章，快捷键字母放在右下角的小黄铜牌上；领袖头像统一成圆形大徽章（阵营色内圈、黄铜外圈），外交页每个领袖下面挂一条阵营色燕尾旗。
- **字体**：标题、城名、数字用衬线体字体栈 `"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif`（思源宋体 / Noto Serif 为 SIL OFL 开源字体，**只引用、不打包**；没有时退回系统宋体）；正文保持原来的无衬线字体栈（中文小字号下更清楚）。

## 4. 可读性与无障碍

- **对比度**：面板正文 `#F4E8CC` 在胡桃木 `#2A1E15` 上约 13:1，次要文字 `#D2C09A` 约 9:1，弱化文字 `#A8946F` 约 5.5:1（均高于 WCAG AA 4.5:1）。地图上的文字（城名、产出数字、徽章字）一律浅色填充 + 深色描边。`prefers-contrast: more` 时次要 / 弱化文字再提亮一级。
- **色盲**：阵营除颜色外保留花纹（徽章圈、横幅圆章用文明编号，徽章圈上有斜纹 / 圆点 / 交叉纹）；敌对单位是红环 + 位置（不只靠颜色）；研究树状态是“形状 + 颜色”；攻击范围是虚线、移动范围是实线；产出硬币靠形状符号区分，不只靠颜色。
- **减少动态效果**：本画风没有新增任何持续动画；`prefers-reduced-motion` 下沿用现有规则（不前冲、不震屏、不出粒子），CSS 过渡时长清零。
- **迷雾可辨认**：迷雾区不是变暗，而是换成完全不同的材质（纸 + 墨线），一眼能分出“现在看得见”和“记得的”；交界有焦褐色边。

## 5. 性能

约束（`handoff-combat-presentation.md`）：dense 场景 p95 不能超出噪声地比平面差；每帧不用 `shadowBlur` 和大面积 `filter`；预渲染进缓存可以。

- 地形：复用 `chunks25d.ts` 的世界空间分块 + 屏幕合成（静止帧一次拷贝，平移时平移合成图、只画新露出的条带）。块画板换成 `drawBasePainted`（`ChunkFrame.paint`），每块画“自己的格子 + 周围一圈邻格”，再裁剪到自己的六边形（略放大 0.8 设备像素防止抗锯齿缝），所以羽化、物件跨块时没有接缝，块按任何顺序拷贝结果都一样。
- 迷雾：屏幕大小的缓存层，键 = 相机 + 迷雾格列表（同平面版）；一次纸纹填充 + 每格一次墨线 `drawImage` + 几条批量描边。
- 每帧：城镇每城 1 次 `drawImage`；单位每个 2–3 次 `drawImage`（框、精灵、属性徽章）；产出每格 1 次；横幅是文字。
- 所有渐变、羽化（`destination-out`）、径向“笔触”只在烘焙时发生。
- 实测见文末。

## 8. 性能实测

方法同 `performance.spec.ts`：Chromium、DPR 2、1280 × 900、dense 场景（1040 格、105 个可见单位、上帝视角），20 帧预热 + 240 帧同步 Canvas 2D 绘制时间，p95，单位 ms。平面 / 绘卷交替测三轮，测量时共享开发机 1 分钟负载约 73（噪声大，表中给三轮数值）。由 `ui-painted.spec.ts` 的 `PAINTED_PERF=1` 测得。

| 场景 | 平面 | 绘卷 |
| --- | --- | --- |
| 整图适配，相机静止 | 11.9 / 6.5 / 6.9 | 6.4 / 4.6 / 4.4 |
| 整图适配，拖动（每帧 1 px） | 15.9 / 13.1 / 13.9 | 4.7 / 3.3 / 4.5 |
| 缩放 1.5，相机静止 | 8.6 / 7.5 / 8.2 | 6.5 / 6.3 / 5.6 |
| 缩放 1.5，拖动 | 9.3 / 8.7 / 8.6 | 6.8 / 4.9 / 5.1 |
| 整图适配，无缓存直接绘制（参考） | 14.6 / 14.4 / 14.3 | 29.8 / 27.5 / 28.5 |

- 玩家实际看到的帧（静止、动画、拖动）绘卷都不比平面慢，而且更快：地形是分块缓存 + 屏幕合成（静止一次拷贝，拖动只画新露出的条带），平面版拖动时每帧重画整张地形。
- 无缓存直接绘制约是平面的 2 倍（每格一张缩放的插画贴图、物件、海岸和边界描边），只出现在“缩放刚变化、相机还在动”的几帧和 `cacheLayers: false` 的参考输出里。
- 首次进入一个缩放档位时要烘焙贴图（约 50–150 ms 一次，之后命中缓存）；这一帧不在 p95 里（预热），玩家看到的是缩放后一次轻微停顿。可以在空闲时预烘相邻档位（见下）。
- 没有 `shadowBlur`；每帧唯一的 `filter` 仍是击倒残影的单个单位灰度（与像素版相同）。

## 9. 做成完整画风还差什么

1. **其余面板**：世界页、外交 / 领袖页（圆形领袖头像 + 阵营燕尾旗）、规章、世代、胜利、传说、动态页的卡片换成同一套双线黄铜框；通知栏的圆形类型徽章；行动栏的圆键和快捷键黄铜牌（§3 已设计）。
2. **地图上剩下的像素元素**：资源 / 巢穴 / 道馆徽章内的像素图标、设施区和改良的图标（现在已放进插画圆牌里）、天气标记、战斗与大事件特效的方块粒子，逐个换成插画版（同一个缓存接口）。
3. **天气**：柔边云团 / 雨线 / 沙尘代替六边形染色。
4. **贴图预烘**：空闲时（`requestIdleCallback`）预烘当前缩放上下各一档，消除首次缩放的停顿。
5. **Max 团体战光环、护盾点（v27）**：v27 合并后在徽章旗上补对应的表现（光环画在徽章外圈，护盾点画在徽章上沿）。
6. **小地图**：绘卷版小地图（羊皮纸底 + 墨线海岸），现在只在 2.5D 显示像素小地图。
7. **测试**：给绘卷画风加一组迷雾不泄露的 Canvas 调用检查（与 `map.spec.ts` 相同的拦截方式）；`performance.spec.ts` 的 dense 场景加一组 `painted`。
