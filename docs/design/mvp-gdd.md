## 2. 兵种映射：文明的兵种体系 → 宝可梦

### 2.1 单位 = 单只宝可梦（而非"训练家 + 队伍"）

**决定：MVP 中一个单位就是一只宝可梦。** 理由：

1. 与文明式六角格移动/占地/无堆叠模型一一对应，寻路、视野都不需要额外抽象层；
2. 战斗快速结算只需要一对数值（攻方 vs 防方），"队伍"会强制引入出战顺序/换人逻辑，违背 D3 的"快速结算"；
3. "捕捉"直接映射为"获得一个单位"，训练家 + 队伍模式下捕捉的语义（入队？入箱？）需要额外 UI 与规则；
4. 训练家的存在感由"文明 = 训练家氏族"承担：城市是氏族营地，领袖是玩家本人。v4 联盟大会再引入"队伍编制"概念，届时新增数据结构，不影响 MVP 模型（D13）。

开拓队是 MVP 唯一的后勤单位：人类小队 + 宝可梦协作者，不可战斗，被敌方交战单位相邻攻击即被消灭（HP 30，无反击）。

### 2.3 进化 = 时代升级

文明的"兵种随时代升级"在本作中就是进化：

- 升级路径由物种进化链固定（如 小火龙 → 火恐龙 → 喷火龙），不做跨链转职；
- 条件：经验达到阈值（基础→一阶 100 经验，一阶→二阶 250 经验）+ 金币（基础→一阶 30，一阶→二阶 80，见 §5.2 表）；二阶进化另需科技「特训法」（§3.4）；
- 进化后 HP 按百分比保留：`新HP = max(1, ⌊旧HP × 新maxHP × 1000 / (旧maxHP × 1000)⌋)`，经验清零重新累计；
- 不进化不会过期：玩家可以为了低成本铺量而保留低阶单位（阶段预算见 §5.1，低阶性价比更高、上限更低）；
- 无进化链的独立物种（卡比兽、大岩蛇、乘龙）不能进化，也不能由进化获得。

## 3. MVP 各系统规则

### 3.1 地图与群系（S1、S2）

- 六角格。地图尺寸为开局参数：**小 24×16（默认，D8）** / 标准 30×20 / 大 40×26。
- 7 种群系：草原、森林、山地、海洋、荒漠、雪原、火山。火山稀有（≤3% 地块），只在地图边缘成簇生成。
- 移动消耗：草原/荒漠/海洋 1；森林/山地/雪原/火山 2。海洋仅水系、飞行定位可进入；火山仅火系、飞行定位可进入。飞行定位的通行权不等于忽略移动消耗；幽灵系仍无视移动消耗。
- 城市格：己方单位可以进入、穿过、停留在己方城市格，消耗按城市所在群系计算，仍遵守同格只能有一个己方单位；他方城市格阻挡移动，攻城与占城按 §3.2 的战斗规则处理，不通过移动进入。
- 水系与海军：§5.2 定位包含“海军”的物种（鲤鱼王线、乘龙）只能在海洋活动；其他水系（杰尼龟线）陆地和海洋都能进入，但不能进入火山。
- 战争迷雾：未探索全黑；已探索显示记忆地形但不显示敌方动态。单位视野 2（侦察系/飞行 3，山地上 +1），城市视野 2。
- 地图生成使用种子化 RNG；同种子同图（D4）。

### 3.2 城市、人口与食物收支（S3、S4、S5）

**建城**：开拓队在非水域、距现有任何城市 ≥4 格处建立营地。开拓队由城市生产（成本 30 生产），建城后该单位消耗移除。**新城初值**：人口 1，食物库存 0，建造队列空，HP=50（无其他建筑）。

**城市中心格**：任何城市所在格自动产出 **2 食物 / 1 生产 / 1 金币 / 0 科研**。这是城市固有属性（每个城市都有，与大本营无关），不占用工作人口，不可移除。

**地块基础产出**（工作地块 = 每轮产出）：

| 群系 | 食物 | 生产 | 金币 | 科研 |
|------|------|------|------|------|
| 草原 | 2 | 1 | 0 | 0 |
| 森林 | 1 | 2 | 0 | 0 |
| 山地 | 0 | 2 | 0 | 1 |
| 海洋 | 2 | 0 | 1 | 0 |
| 荒漠 | 0 | 1 | 1 | 0 |
| 雪原 | 1 | 0 | 0 | 1 |
| 火山 | 0 | 2 | 0 | 2 |

**工作地块与领地**：城市工作半径 2；人口每 +4，半径 +1。默认可工作群系：草原、森林、山地、海洋、荒漠；雪原、火山需科技「气象观测」后才可工作。领地是各城市工作半径的覆盖集合，不是地块的单一所有权；不同文明、不同城市的领地可以重叠。重叠不改变“一格同时只能被一座城市工作”的规则；中立营地不产生领地（D39）。

- 一个地块同一时刻只能被一座城市工作；跨城半径重叠时**先到先得**（已被他城工作的格不参与本城分配）；城市被占领时其工作格全部释放，由新主重新全部分配。
- 自动分配优先级：在可工作且未被占用的格中，按（食物, 生产, 金币, 科研）字典序取最大者；同值按格子 (r, q) 升序。
- 自动分配只在三种时候触发：建城或开局时填满全部人口；人口增长时只给新增的 1 人分配；城市被占领时由新主重新全部分配。玩家通过 AssignWork 主动少分配的人口一直作为观测者，不会被自动补位。
- 手动锁定：玩家可锁定/解锁任意本城工作格；锁定格超出半径或城市易主时锁定自动解除。
- 工作格失效（被他城先占、超出半径等）时，该人口变成观测者，等待玩家重新分配，不触发自动补位。

**食物收支**：

- 每人口每轮消耗 **2 食物**；盈余 = 城市食物总产出 − 2×人口；盈余 > 0 时存入库存；
- 库存 ≥ `20 + 10×当前人口` → 人口 +1 并扣除该数量；**每城每轮末至多增长 1 人口**；
- 盈余 < 0 时扣库存；库存为 0 仍不足且人口 > 1 → 人口 −1（饥荒），库存归 0；**人口下限为 1**（人口 1 时不再扣减，仅停止增长）；
- 饥荒减少人口时，先释放未锁定工作格中自动分配优先级最低者（产出字典序最小，同值取格子 (r, q) 最大）；若全部工作格都锁定，则释放锁定格中同一最低优先级者。释放后不触发自动补位；
- 城市被占领的当轮，该城完全不结算（不产出、不耗粮、不增长）。

**观测者**：未分配工作地块的人口，每个每轮提供 **1 科研**。

**城市 HP**：`50 + 20×已建成的非大本营建筑数`。大本营不计入建筑数。

**占领**：城市 HP 到 0 即被攻击方占领：建筑与人口保留，`capturedHp=50`，即 HP 恢复至 50，**当轮完全不结算**，从下一个轮末开始为占领方结算。若城内有休养中单位，这些单位随占领移除（§3.7）。

### 3.5 单位与移动（S12）

- **行动点**：每单位每回合 1 行动点；移动 / 攻击 / 捕捉 / 进化 任一执行即消耗。当回合新训练、新捕捉、刚完成进化的单位行动点为 0（下一回合起正常）。
- 无堆叠：同格只能有一个己方单位。
- **训练**：城市消耗生产训练可训练物种。**可训练 = 已登记 ∩ 科技门槛**：已登记集合 = 御三家所选基础形态 ∪ 曾捕捉/拥有过的物种（获得时登记，死亡/解散不取消）；高速系（小火马线、拉达）另需科技「骑行驯服」（Q06）。
- **训练成本（唯一公式）**：`成本 = ⌊(HP + A + D) / 8⌋`，HP/A/D 取 §5.2 表中该物种值（例：小火龙 ⌊162/8⌋ = 20，怪力 ⌊288/8⌋ = 36）。
- **建造队列**：每城队列最多 **5 项**；取消首项时已投入进度作废、不退款；重排/取消非首项无进度损失。每城每轮生产阶段至多完成 **1 项**；首项完成后离队，**溢出进度全额结转**到队列下一项，但即使足够也不能在同轮继续完成，队列为空则溢出丢弃。
- **待出场**：单位订单完成时若城市相邻 6 格没有该单位可进入的空格，完成项仍离队并转入独立的"待出场"记录：不占 5 项配额、不阻塞后续生产，出场前不生成单位、不占维护、不耗行动、不计入单位数。每轮生产阶段先按（进入轮数，原订单 ID）升序逐条重试，有几个相邻可进入空格就可出场几个；落点先过滤该单位不能进入的地形，再按（距离, 格子索引）选择，仍限相邻 6 格。新产生的待出场记录下一轮才参与重试。待出场记录已离队，不能通过队列调整命令取消或重排。
- **维护费**：每单位每轮金币 = 阶段数（基础 1 / 一阶 2 / 二阶 3；休养中照付）；开拓队无阶段，维护 0。
- **赤字硬约束**：金币不允许为负。轮末金币结算（§3.11 第 3 阶段）后若余额 < 0，立即强制解散：按维护费降序（同维护费按实体 ID 降序）逐个解散己方单位，每解散 1 个，余额 += 其维护费，直至余额 ≥ 0。解散不返还成本、不触发濒死、不计击坠。

### 3.6 捕捉（S10，D11）

- 前提：科技「驯化」。消耗品库存为玩家级资源：精灵球 20 金币、超级球 45 金币（需「精灵球工艺」），在任意己方城市购买，库存无上限。
- **只能捕捉野生宝可梦**（D11），不能捕捉其他文明的已驯服单位（v4 再评估）。
- 流程：将野生单位 HP 压低 → 相邻使用精灵球/超级球（捕捉时选择球种，消耗对应库存）。
- 捕捉成功率（整数百分比），**计算顺序固定**（Q04）：

  `p = ⌊ ( ⌊(HPmax − HP) × 60 × 球倍率 / (HPmax × 1000)⌋ + 观察加成 ) × 稀有修正 / 1000 ⌋`

  即：先按球倍率算基础概率并取整 → 加观察加成（「野外观察」已研究 = +10，否则 0）→ 最外层乘稀有修正（普通 1000 / 稀有 500）再取整。种子化 RNG 掷 [0,99]，< p 则成功。
- 例 1（非稀有）：野生豪力 HP 15/74（§5.2"豪力"行），精灵球：基础 = ⌊59×60×1000 / 74,000⌋ = 47；无观察加成、非稀有 → **47%**；超级球：基础 = ⌊59×60×1500 / 74,000⌋ = **71%**；已研究「野外观察」→ (47+10)×1000/1000 = **57%**。
- 例 2（稀有）：野生卡比兽 HP 20/130（§5.2"卡比兽"行），超级球 + 已研究「野外观察」：基础 = ⌊110×60×1500 / 130,000⌋ = 76；(76+10)×500/1000 = **43%**。
- 成功：成为己方单位（保留当前 HP）；失败：球消耗，目标获得**激怒**状态（下次攻击伤害 ×1200/1000，触发一次后移除）。

### 3.7 战斗快速结算与濒死（S13、S14，D7）

**公式（整数，向下取整）：**

```
若攻击被免疫（防守方 immunities 含攻击方属性）或克制倍率 E = 0：伤害 = 0（无效）
否则：伤害 = max(1, ⌊ 攻击A × 威力P × E × 地形T × 随机R / (防御D × 1,000,000) ⌋)
```

- E（克制，百分比）：无效 0 / 甚微 50 / 普通 100 / 拔群 200（「属性研究」后 220）。城市没有属性：攻击城市及城市反击时 E 均固定为 100，城市不适用属性免疫（D33）。
- T（地形，百分比），**判定顺序固定，掩体优先**（Q04）：① 防守方在森林/山地 → T=80；② 否则攻击方居高临下（山地 → 更低地形）→ T=120；③ 否则 T=100。两个条件同时成立时按①，即 T=80。城市所在格为森林/山地时，城市防守同样适用掩体。
- R（随机）：种子化 RNG 整数 [85, 100]。同 seed + 同命令序列 → 同结果（D4）。
- P（威力）：MVP 全物种 P=10（§5.2 显式字段）；反击 P=5。
- 反击：防守方存活且攻击方在其射程内 → 以 P=5、R=100（固定无随机）反击一次。城市以固定 A=30（杰尼龟开局加成后 ×1150/1000 = 34）、P=5 反击；**城市反击射程固定为 2**，仅攻击方距城市 ≤2 且城市在本次攻击后 HP>0 时触发。射程 3 的攻城单位可在反击范围外攻城（D33）。
- 攻城：对城市用同一公式，城市 D=50；「投石改装」后攻城系 ×1750/1000。
- **濒死撤退（D7）**：文明所属单位 HP→0 时不死亡，立即撤退至最近的己方城市（六角距离最近，平局取城市实体 ID 较小者），HP=1，进入**休养**，计数 = 3：
  - 休养单位进入该城的"休养槽"：**不占地图格**、不阻挡、不参与任何战斗；不能移动/攻击/捕捉/进化/被分配；维护费照付，可被赤字解散；
  - **每轮末（含进入休养当轮的轮末）计数 −1**；到 0 时解除休养，HP 恢复至 `⌊maxHP × 250/1000⌋`；落点先过滤该单位不能进入的地形，再按（距离, 格子索引）从该城相邻 6 格选择最近可进入空格；若相邻 6 格没有可进入空格，留在休养槽内每轮末重试；同城多个单位同时恢复或等待落格时按单位实体 ID 升序处理，未落格者不重复恢复 HP；
  - 行动阶段进入休养者初始计数 3，在轮末第 5 阶段首扣；**第 6 阶段野生攻击导致的新休养直接以计数 2 入槽**，等价于已执行当轮首扣，不重复扣减、不触发回血或恢复；
  - 休养所在城市被占领 → 该单位移除；
  - 补偿代价：3 轮战力真空 + 维护费 + 仅恢复 25% HP + 失守风险；野生单位无濒死，HP→0 直接移除。
- **经验获取**：攻击或反击造成非零伤害 +10；击坠额外 +40×目标阶段数（基础 40 / 一阶 80 / 二阶 120；击坠文明单位 = 使其进入濒死撤退）。同一次攻击或反击中，同一单位先把伤害与击坠经验相加，再乘所有适用倍率（小火龙开局 ×1150/1000、「特训法」×1250/1000，两者连乘），最后只向下取整一次；例如基础经验 50、两种倍率同时适用时为 `⌊50×1150×1250/1,000,000⌋=71`（D33）。捕捉、助攻不提供经验。消灭后勤单位（开拓队）**只计击坠数、不提供击坠额外经验**（伤害经验 +10 正常）。**城市反击造成的击坠计入该城所属文明的击坠数，任何单位不因此获得经验。**经验累积无上限，进化后清零。
- **击坠计数**：使野生单位 HP→0，或使敌方文明单位进入濒死撤退，均计击坠 +1（含反击造成者；解散/失守移除不计）。

### 3.9 胜利、淘汰与计分（S15，D8、D9）

- **轮**：一轮 = 所有存活文明各完成一次行动回合。**轮上限默认 100**（开局参数 100/200/300，D8）。轮上限为 N 表示完整进行第 1 至第 N 轮；所有存活文明均完成第 N 轮行动，第 N 轮轮末阶段 1–7 结算后，才在阶段 8 计分终局，不开放第 N+1 轮（D36）。
- **征服胜利（D9）**：攻下某文明的**大本营**（其初始城市）→ 该文明立即淘汰。**淘汰结算顺序**：在大本营易主的原子命令内依次执行——① 大本营控制权转移 → ② 余城全部变为**无主中立营地**（HP 恢复至 50，不产出、不反击、不增长，任何文明无需宣战即可攻击占领）→ ③ 该文明单位（含休养中）全部移除 → ④ 定格其计分项快照（此时其城市数=0），仅用于终局排名表。当除己方外所有文明均被淘汰 → 立即获胜。征服判定在涉及大本营控制权变更的原子命令结尾立即执行。玩家大本营失守 → 游戏结束（失败）。
- **轮上限计分**：到达上限时按以下各项求和，**胜者只在终局时仍存活的文明中产生**（被淘汰文明以定格分参与排名，不参与胜者判定）；最高分获胜（「联盟规章」后总分 ×1200/1000 取整）：

| 计分项 | 分值 | 定义（I-07） |
|--------|------|--------------|
| 城市数 | ×80 | 终局时刻己方实际控制的城市数（不含无主中立营地） |
| 总人口 | ×10 | 终局时刻己方所有城市人口之和 |
| 拥有物种数 | ×5 | 历史登记集合：曾通过训练/捕捉/进化**获得过**的不同物种数；获得时登记，死亡/解散不取消 |
| 完成科技 | ×20 | 终局时刻已解锁科技数；D44 的提高权重实验未改善平衡，D45 决定不采用，保持 ×20 |
| 击坠数 | ×2 | §3.7 定义的击坠计数（含反击、含野生、含消灭后勤单位如开拓队；不含解散与失守移除） |

- **平分规则**：总分相同 → 依次比较 城市数 → 总人口 → 完成科技数 → 击坠数；仍相同则**并列胜利**（结果支持多胜者名单）。

### 3.10 外交状态机（S17，D12）

每对文明之间独立维护一个关系状态，**开局全部和平**。

```
和平 ──宣战（任意时刻，无成本、无冷却，命令 DeclareWar）──▶ 战争
战争 ──停战（开战满 5 轮后可提出，命令 MakePeace；需对方接受）──▶ 和平
和平 ◀── 冷却：停战达成后 10 轮内双方不得再互相宣战（「联盟规章」后 5 轮）
```

- 和平：不能攻击/捕捉对方单位，不能攻击对方城市；可进入对方领地格，不能进入对方城市格。
- 战争：可自由攻击对方单位与城市。
- **停战提议生命周期**：开战满 5 轮后才可提出停战；提议在提出方行动回合发出；**对方在其下一个行动回合必须回应**（AI 立即按 §3.14 决策；玩家手动选择），逾期未处理视为拒绝；提议不可撤销；拒绝后 5 轮内不得再向同一文明提出。
- **冷却规则**：停战达成后双方进入冷却，时长以**达成时刻**为准——任一方已研究「联盟规章」则 5 轮，否则 10 轮；冷却一旦开始不再因科技完成而变化。
- **可见性**：所有文明之间的外交状态对全员公开（含 AI–AI 关系）。战斗预览所需的可见敌方单位所属文明是否已研究「属性研究」、可见城市 HP 与反击攻击力属于可观察交战信息，可以提供给玩家；反击攻击力可能暴露杰尼龟选择。仅限这些项目，其他经济、科研进度仍隐藏（D35）。
- **领地可见性（D39）**：每格记录覆盖它的文明 ID 集合，排序并去重，不使用单一领地所有者；界面按各文明集合分别绘制边界，重叠格的各方边界都显示。当前可见格才更新实时归属，隐藏格保持历史记忆；从未观察到归属与已观察到无覆盖必须区分。可见边界可能透露附近隐藏城市的大致位置，但城市本身仍按视野隐藏。
- 「联盟规章」（T3）只提供：终局计分 ×1200/1000；停战冷却 10 → 5 轮。无其他隐藏效果。

### 3.11 回合结构与轮末结算顺序（对齐技术文档 `resolveRoundEnd`）

玩家在行动回合内可下达任意数量合法命令（移动/攻击/捕捉/进化/建城/生产/研究/购买球/工作地块分配/宣战/停战），以「结束回合」收尾。所有存活文明各行动一次后进入轮末结算。

**产出快照（D30）**：轮末结算开始时，先对所有城市的四类产出（食物、生产、金币、科研，包括观测者）做一次快照，阶段 1–4 共用这份快照。本轮新增的人口、新完成的建筑、新分配的地块都从下一轮才开始产出。

随后按**固定顺序、每阶段恰好一次**执行：

1. 城市食物结算：§3.2 收支、增长与饥荒；
2. 生产结算：先按 §3.5 的顺序重试既有待出场记录；再推进各城生产队列，每城至多完成 1 项，完成项离队并结转溢出，无法出场者转入待出场记录且本轮不重试；
3. 金币结算：余额 += 快照金币总产出 − 本阶段实际存在单位的总维护费；阶段 2 刚出场的单位当轮付维护费，待出场记录不付。余额 < 0 触发 §3.5 强制解散；
4. 科研结算：按 §3.4 将储备科研与快照科研产出计入当前课题，或存入储备；每文明每轮最多完成 1 项科技，溢出进入储备；
5. 单位状态：休养计数 −1 与恢复；己方领地内非休养单位回血 +5（「伤药调配」后 +10）；
6. 野生阶段：§3.12 刷新判定与野生行动（中立规则实体，不进入 turnOrder）；本阶段攻击造成的新休养按 §3.7 直接以计数 2 入槽，不新增轮末阶段；
7. 视野更新：按新位置重算各文明可见集合；
8. 轮上限判定：完整进行第 N 轮行动并完成本阶段之前的轮末阶段 1–7 后，若达到上限 N → §3.9 计分并结束；否则进入下一轮，刷新行动额度，不开放第 N+1 轮（D36）。

### 3.14 AI 性格意图（S16，I-08；实现细节留 coder）

三种性格只改变目标优先级与时机判断，不改变规则。AI 与玩家同规则同信息（不读隐藏状态）。**度量口径（Q07）**：AI 评估中的一切"对方军力/城市数"只使用其**已观察信息**（当前可见 + 已探索区的最后已知），休养中单位不计入战斗单位数；"城市损失"统计窗口 = 本场战争开始以来（进入战争状态时清零）；"低速扩张" = 无战争时每 8 轮至多生产 1 个开拓队；"接壤" = 至少一座已观察的对方城市距己方地图单位 ≤5 格；"邻近战区" = 距己方任一城市 ≤6 格。

| 维度 | 扩张型 | 好战型 | 保守型 |
|------|--------|--------|--------|

### 5.3 成本、产出与 100 轮节奏（I-02）

- 科技成本：T1 20×3 = 60，T2 40×4 = 160，T3 70×5 = 350，全树 570。
- 科研产出估算（单文明混合打法）：轮 1–25 约 2/轮（观测者 + 山地格）= 50；轮 26–70 约 5/轮（2–3 城 + 观测站）= 225；轮 71–100 约 8/轮 = 240；**100 轮合计 ≈ 515 ≈ 全树的 90%**。
- 结论：科技专精打法 100 轮可完成 10–11 项；混合打法完成 8–10 项；T1 在约轮 25 前完成，T2 在轮 40–70，T3 从轮 70 起。科技树不会被系统性跳过，也不会早早点完失去选择压力。
- 城市食物需求 `20 + 10×人口` 线性增长；草原城前期 5–6 轮/人口，雪原/荒漠城显著更慢 → 驱动争夺草原/海岸。
- 维护费随阶段线性增长，赤字触发强制解散（§3.5）。

### 5.4 克制强度上限与滚雪球抑制

- **克制上限规则**：等阶对局中，任意有效克制组合（含「属性研究」E=220、居高临下 T=120、R=100 的极端情况）单次伤害 ≤ 防守方最大 HP 的 **60%**。校验方式为全对全脚本（39×39 按等阶过滤）：当前最坏对 = 腕力 → 喵喵，30/50 = 60.0%，达标（脚本证据见 reports/design.md）。
- **上限取值说明（v0.3 起 55% → 60%，补登记）**：55% 会迫使常见克制对（格斗→普通、火→草）的 HP/A 比例失真、挤压定位差异；60% 仍满足设计硬目标"等阶克制无法单击秒杀"（单击 ≤60%，秒杀需 >100%），且当前最坏对恰好压线，说明数值已是最紧可行解。未来新增物种由同一脚本回归校验。
- I-03 处理：不再有"A>95 降 P"特判——全表 P=10，靠数值设计满足上限；免疫用通用 `immunities` 字段（当前仅小拳石线/大岩蛇 = 电）。新增物种时同一脚本即回归校验。
- **滚雪球抑制**：(a) 维护费赤字强制解散；(b) 攻城需多轮（城市基础 HP 50，每座非大本营建筑 +20，且城市会反击），速攻受反击与战力门槛约束；(c) 捕捉机制是劣势方的追赶通道；(d) 轮上限计分使"拖"成为劣势方合法策略；(e) 濒死撤退降低单次交战的决定性，但 3 轮休养 + 25% HP 恢复限制其滚回速度。
- **随机数抑制**：R∈[85,100] 使单次伤害波动 ≤15%。

### 5.5 平衡验证方法与验收批次（I-09）

无头 AI 对 AI 批量模拟器（coder 的技术系统 S23），分两层：

- **缺陷发现批次**（每次 M3/M4 规则变更、每次数值迭代后）：10 种子冒烟 → 100 种子探索趋势；只用于发现问题，不作为平衡结论。
- **发布前固定样本烟测**（M6 放行前）：初始 **100 个种子**；1v1 每种子 2 局（互换出生席位）= 200 局；1v3 每种子 1 局 = 100 局；种子在两批间复用（Q09）。它是固定样本烟测，不是置信结论。
- **对局有效性（D38）**：`aborted` 只指触发命令上限的对局，剔除出胜率统计并单独报告，aborted 比例 >5% 则验收不通过。迷雾下合法尝试被拒属于正常信息反馈，不影响对局有效性，照常计入全部指标并逐局报告数量；其他原因的被拒、非法种子或模拟异常属于缺陷，相关对局标 `defect`，从指标中剔除并逐条报告，目标为 0。不得把 defect 归入 aborted、暗中替换种子或记作计分；同时保留“任何无效命令都剔除”的旧严格口径作为对照。
- **统计口径（Q09）**：两两胜率与先手胜率只在 1v1 局统计；1v3 只统计整局胜者的性格分布；并列胜者各计 0.5 胜。滚雪球指数的"第 30 轮领先者"= 该轮末计分公式得分唯一最高者；指标分母只含**正常终局、实际到达第 30 轮末且该轮唯一领先**的对局，并列领先、中止局与未满 30 轮终局均不计入该指标。提前终局仍正常计入征服占比、平均终局轮数、胜率等其他适用指标；不得用终局胜者或较早快照回填第 30 轮领先者。模拟报告须单列提前终局数与滚雪球指标有效样本数。
- **统计输出（D18）**：每个比率指标同时输出点估计、样本量 n、实际独立种子数与 Wilson 95% 区间，并保留分子/分母定义。1v1 互换席位的两局来自同一种子且具有相关性，不算两个独立样本；区间只作描述，不作为额外放行条件。n=0 时点估计与区间记为不可计算，不伪造 0% 或 100%。
- **追加规则（D18）**：放行按点估计判定。某项点估计不达标，或比率点估计距适用阈值不足 5 个百分点，就为相关配对或指标追加 100 个新的独立种子，按原对局安排合并重判；仍不达标则不放行。双侧阈值取距最近一侧，恰好 5 个百分点不追加；轮数、捕捉次数等非比率指标不套百分点，但不达标仍追加。报告分列初始、追加与合并结果，独立种子去重。

验收指标与目标（按 100 轮默认局校准）：

1. 征服终局占比 ≥40%（过低说明攻城太难/轮上限过短）；
2. 平均终局轮数 70–95；
3. 先手胜率 ≤55%；性格两两胜率 40–60% 只作为**好战对扩张**和**好战对保守**的放行条件，两个方向都报告但按同一种子席位互换后的整体点估计判定。D45 接受保守型是较弱的性格，因此**保守对扩张**仍照常报告双方胜率，但仅作参考，不作为放行条件，也不得用它抵消其他硬条件失败；
4. 无属性优势击坠占比 >25%（D37）：分母是文明所属宝可梦的攻击或反击造成且计入该文明击坠数的宝可梦击坠，目标包括野生宝可梦；分子是其中实际最后一击克制倍率 E≤100 的事件（含 E=50）。排除城市反击、后勤目标、野生攻击来源、赤字解散与大本营失守清理；逐局保留攻防实体类别、属性、实际 E 与是否反击，不从物种基础表推测最后一击倍率；
5. 滚雪球指数：第 30 轮领先者的最终胜率 ≤75%；
6. 捕捉使用率：平均每局 3–10 次。

## 附：与 coder 技术文档的接口约定（供 review 交叉核对）

1. 所有数值（§5.2、§5.3、克制表 §3.8、产出表 §3.2、刷新权重 §3.12）必须落在数据文件中，禁止硬编码进逻辑。
2. 战斗结算函数必须是纯函数：`(攻方快照, 防方快照, 地形, rng) -> (伤害, 反击伤害)`，rng 只暴露 `nextInt(min, max)`。
3. MVP 事件日志（D13：只含 MVP 实际产生的事件）：移动/伤害/击坠（含濒死撤退）/捕捉尝试与结果/进化/建城/城市占领/研究完成/宣战/停战/淘汰/终局。
4. 不预建 v2–v4 空字段（D13）：资源层、巢穴实体、teamId、wonder 等到对应版本再加字段并写存档迁移；MVP 只保留命令/观察/版本/确定性架构约束。
5. 倍率表示：本文百分比在技术实现中以千分比存储（E=200 ↔ 2000，R=85 ↔ 850）；统一"先乘后除、单次向下取整"。
6. 字段/命令补齐提示（coder R1 建模依据，语义以本文为准）：`SpeciesDef` 需含 power/range/stage/rare/immunities/spawnBiomes/训练成本/进化成本；建筑产出需含金币；城市需 HP/生产队列/独立待出场记录/工作地块锁定；单位需休养计数/激怒状态；玩家需外交关系/球库存/御三家加成/物种登记集合/击坠计数；命令需含宣战/停战/购买球/工作地块分配。
7. 术语对齐：本文"轮"对应 `round`/`roundLimit`；§3.11 对应 `resolveRoundEnd` 阶段数组；野生单位 = `owner = 无` 的单位，不进入 `turnOrder`；中立营地 = 无主的 `CityState`。
